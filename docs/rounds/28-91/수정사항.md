# 28-91 수정사항 — 시연 데이터·공개 지표 제거 (참고 v12 대조 1단계)

28-90의 대조표(`../28-90/참고_v12_대조.md`) "없앨 것" 중 e2e 얽힘 때문에 미룬 두 항목이다. 참고 시안은
**빈 상태에서 시작**하고 실적 숫자를 내걸지 않는다. 우리는 28-78이 시연 시드를 되살린 뒤 열한 라운드
(28-79~28-88)를 그 시드를 가리고·빼고·지우는 통로를 만들고·그 규칙을 지키는 가드를 네 번 고쳐 쓰는 데 썼다.
시드가 없으면 그 전부가 필요 없다.

## 남긴 것과 이름

- `PlatformService.SEED_PARTNER_ID` → **`LEGACY_PARTNER_ID`**(`P-001`). 남은 용도는 28-41 이전 스냅샷의 단일 프로필을
  옮겨 붙이는 것 하나다. `usePartnerId()`·`PartnerCard`의 세션 없는 폴백도 같은 값이다(파트너 화면은 로그인 뒤라 실제로는
  닿지 않는다).
- 옛 스냅샷에 `seeded: true`가 남아 있어도 읽을 때 그냥 지나간다 — 스냅샷 검증은 그 필드를 본 적이 없다(여분 필드).
- 로컬 모드의 "시연용 관리자 계정 / 인증번호" 안내는 **계정**의 시연이지 데이터가 아니라 그대로다(사용자 결정: 로컬 모드 유지).

## 바꾼 테스트

- `bootstrap.test` "빈 저장소로 부팅하면 요청 0건" — 부팅은 저장소를 건드리지 않고(쓸 것이 없다), 첫 요청부터 저장된다.
  28-79-02의 두 테스트는 시드의 `requests[0]`에 사진을 붙이고 있었으므로 요청을 하나 만들고 붙인다.
- `serverlessState.test`의 모듈 상태 하한 6 → 3 (`api/publicStats.ts`의 `memo`·`inflight`·… 가 사라졌다).
- `Landing.test`는 28-89-B 배치 테스트만 남았다.
- **e2e 여정**: 파트너2 입찰과 맞춤 토글이 쓰던 시드 일감 둘('욕실 천장에서 물이 새요' 누수·서울 강서구,
  '거실 콘센트 교체 3곳' 전기·서울 마포구)을 **고객이 위저드로 직접 올리는** 단계(`postRequest`)로 바꿨다. 지급 대기
  4→1, 지급 뒤 대기 3→0, "정산 완료" 필터 4→1행. 히어로 지표 부재 단언 둘과 시연 삭제 카드 단계 아홉 개 삭제.
- **서버 e2e**: 28-85-05 익명 방문자 절(6단계) 삭제 → 59 → 53단계.
