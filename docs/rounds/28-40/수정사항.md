# 28-40 수정사항 (Claude) — 회원 탈퇴·파기 라운드

기반: `28-39` 복사본(스크래치 wf28-40)에서 작업. 28-39 감사 4건 전부 반영.

## 28-39-01 · 탈퇴·파기 도메인 [반영]

- `AuthService.withdraw(role, password)` — 로그인·비밀번호 확인 필수. 이름→"탈퇴 회원", 휴대폰·비밀번호 비움, 사업자번호·조회 상태·정산 계좌·거절 사유 삭제, `withdrawnAt` 기록, 해당 역할 세션 종료, 게이트 1회 안내(`consumeNotice()`, 비영속). 탈퇴 계정은 `login()` 거부, `register()` 중복 검사에서 제외(같은 번호 재가입 허용). 스냅샷 로드 검증에 `withdrawnAt` 형식 추가.
- `AuthService.purgeAccount(accountId)` — 탈퇴 계정만 기록 삭제(법정 보관 기간 경과 후 관리자 실행).
- `PlatformService.openTransactionCount(customerId)`(수락·예약·시공 중 + 완료 후 미결제) / `partnerHasOpenWork()`(진행 중 작업 또는 지급 대기) / `anonymizeCustomer(customerId)`(저장소 내부 객체 갱신 `RequestStore.anonymizeCustomer`, 거래·결제 기록은 보존). 도메인 테스트 3건(auth 탈퇴 파기·재가입·왕복 / 파기 규칙·왕복 / platform 차단 규칙·비식별화) → vitest 186→**189**.

## 28-39-02 · 마이페이지 회원 탈퇴 [반영]

- 고객·파트너 마이페이지 하단 **회원 탈퇴** 카드(`.withdraw-card`): 즉시 파기 항목·법정 보관 항목(거래 5년·분쟁 3년) 안내, 비밀번호 확인, 동의 체크(미체크 시 안내), "회원 탈퇴". 고객은 진행 중 거래, 파트너는 진행 중 작업·지급 대기가 있으면 거부 문구. 탈퇴 후 고객 요청 표시명 비식별화 → 로그인 게이트로 복귀 + "탈퇴가 완료되었습니다…" 1회 안내(`[data-gate-notice]`).

## 28-39-03 · 관리자 회원 탭: 탈퇴 상태·파기 [반영]

- 상단 지표 "탈퇴(보관 중)" 추가, 필터 **탈퇴**(고객/파트너 필터는 탈퇴 계정 제외), 상태 컬럼 "탈퇴 · 날짜" 태그, 휴대폰 "파기됨", 탈퇴 행은 승인/거절/정지 대신 **파기** 버튼만(툴팁에 보관 기간 안내).

## 28-39-04 · e2e + 실측 [반영]

- e2e 6단계 추가(62→**68**): 탈퇴 비밀번호 오류 거부 / 탈퇴 완료→게이트 안내 / 탈퇴 계정 로그인 거부 / 관리자 탈퇴 회원 1건(파기됨) / 파기→목록 제거 / 같은 번호 재가입(OTP 발급). 전 여정 무회귀.
- 실측 3장: 탈퇴 카드(비밀번호 오류), 게이트 안내, 관리자 탈퇴 행.
