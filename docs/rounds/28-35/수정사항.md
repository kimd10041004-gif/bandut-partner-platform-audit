# 28-35 수정사항 (Claude) — 파트너 승인 라운드 (시안 4)

기반: `28-34` 복사본(스크래치 wf28-35)에서 작업. 28-34 감사 4건 전부 반영.

## 28-34-01 · 파트너 승인 도메인 [반영]

- `Account.approval?: 'pending'|'approved'|'rejected'` + `rejectReason?` — 파트너 가입 시 `pending`, 고객은 승인 대상 아님.
- `approvePartner(id)` / `rejectPartner(id, reason)`(사유 필수, 파트너 계정만) / `partnerApproval()`(현재 파트너 세션 상태). 거절돼도 로그인은 가능(사유 확인용). 저장소 검증(approval 값 집합) + 왕복. auth.test +1 → vitest 175→**176**.

## 28-34-02 · 파트너 센터 승인 게이트 [반영]

- `ApprovalBanner` — 대시보드·일감 탭 상단: 대기("사업자 정보 검토 중 — 승인 후 입찰 가능") / 거절(사유 표시). 일감 탭: 승인 전 **입찰 폼 미표시 + "이 일감에 입찰" 버튼 비활성**(툴팁 안내). 열람은 허용.

## 28-34-03 · 관리자 승인 액션 [반영]

- 회원 탭: 승인 컬럼(대기/승인/거절 — 거절은 사유 툴팁), **승인** 버튼, **거절** 버튼 → 사유 입력 폼 → 거절 확정. 지표 "승인 대기 파트너" 추가.

## 28-34-04 · e2e + 실측 [반영]

- e2e 2단계 추가(46→**48**): "승인 전 파트너 입찰 차단(배너 + 버튼 비활성)" → 관리자 로그인·회원 탭 "관리자 파트너 승인" → 기존 입찰 여정 이어짐. 관리자 로그인 시점이 앞당겨져 기존 스텝은 "세션 유지" 확인으로 조정. 전 여정 무회귀.
- 실측: 승인 대기 배너·버튼 비활성 true, 관리자 승인 후 상태 '승인' true. 스크린샷 2종.
