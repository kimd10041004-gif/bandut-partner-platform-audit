## 6. 이 컨테이너에서 확인하지 못한 것 / 알고도 남긴 것

- 라이브 도메인은 이그레스 정책이 막고 있어 **직접 열 수 없다**. 화면 동작은 로컬 프로덕션 빌드에서
  확인했고, 배포 반영은 병합 뒤 `deploy-check`로 §7에 적는다.
- **서버 모드에서 익명 방문자는 스냅샷을 못 받는다**(구현 중 발견). 그래서 28-81이 지표를 서버 모드로
  옮겼어도 익명 방문자에게는 여전히 보이지 않는다. 공개 집계 엔드포인트가 필요하고 그것은 보안 판단이
  따르는 새 API라, 이번 범위 밖으로 두고 `수정사항.md`「하지 않은 것」에 적었다.
- **사용자 눈에 보이는 이번 배포의 변화**: 견적함·고객 홈의 업체 카드에서 시연 시드가 만든 실적이
  사라진다(완료 3건 · 낙찰률 100% → 완료 0건 · 낙찰률 —). 히어로 지표는 28-81 이후와 같이 계속 없다.
