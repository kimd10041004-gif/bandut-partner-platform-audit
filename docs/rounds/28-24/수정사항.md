# 28-24 수정사항 — 28-23 감사 4개 항목 전부 처리 (브랜드 에셋 적용 라운드)

작업 방식: 기존 규칙 그대로 — 28-1~28-23은 일절 수정하지 않고 스크래치 복사본(`scratchpad/wf28-24`)에서 수정 후 `28-24` 스냅샷 생성. 사용자 제공 브랜드 에셋 5종("이미지는 잘 활용해줘") 적용 — 텍스트 브랜드를 실제 브랜드로 교체.

## 항목별 수정 내용

### 28-23-01 [상] 로고·파비콘 → 적용
- 로고 원본에서 심볼(집+체크)을 임계값 bbox로 정밀 추출 → `public/brand/logo-mark.png`(128px)·`favicon.png`(64px).
- 헤더 로고 마크를 "반" 텍스트 → 공식 심볼 이미지로 교체(30px, radius 8, object-fit cover). index.html에 파비콘 링크 + `<title>` "반듯집수리"로 정정.

### 28-23-02 [상] 랜딩 히어로 비주얼 → 적용
- 히어로를 2단 그리드(좌 카피 / 우 브랜드 메인 비주얼)로 — 텍스트 없는 **장면 크롭**(하단 58%) 사용, 라운드+보더 1px. 720px 이하 세로 스택 + 이미지 300px 높이 제한(가로 스크롤 없음 e2e 유지 확인).

### 28-23-03 [상] 서비스 카드 이미지 → 적용
- 주거 케어/스마트홈 IoT/에어비앤비 세팅 카드 상단에 전용 장면 크롭(4:3, object-fit cover, lazy) 적용 — 카드 패딩을 이미지 풀블리드 구조(svc-body)로 재편.
- 서브 카피를 에셋 문구와 정렬: "입주 전, 집 전체 점검" / "설치 전 사진상담" / "오픈 전 공간 점검".

### 28-23-04 [중] 에셋 규약 → 문서화
- `public/brand/` 웹 최적화본만 커밋(원본 금지) — 6개 파일 총 **272KB**(목표 500KB 이하 충족). 파이프라인: PIL로 장면 크롭 + 리사이즈(680~760px) + JPEG q80~82.
- DESIGN_SYSTEM에 "브랜드 이미지" 절 신설(규약·사용 규칙·다크 모드 오버레이 금지).
