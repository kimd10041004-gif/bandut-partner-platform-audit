# 28-52 수정사항 (Claude) — 계정 보안 라운드

기반: `28-51` 복사본(스크래치 wf28-52)에서 작업. 28-51 감사 4건 전부 반영.

## 28-51-01 · 비밀번호 해시 [반영]

- `domain/hash.ts` 신설: 의존성 없는 동기 SHA-256(`sha256Hex`) + 솔트·반복 해시 `hashPassword(pw, salt = randomSalt(), iterations = 2000)` → `s256$<iter>$<salt>$<hex>`, `verifyPassword`(형식 검사 + 전량 비교), `isPasswordHash`. `hash.test.ts` 신설(빈 문자열·`abc`·56바이트 표준 벡터, 결정성·솔트 상이·검증·반복 0 거부).
- `Account.password` → `passwordHash`, `adminPassword` → `adminPasswordHash`(시드 비밀번호는 기동 시 해시). 가입·비밀번호 변경·탈퇴·로그인 전부 해시 경로. `AccountView`·`listAccounts`·`accountFor`는 해시 제외.
- **구 스냅샷 마이그레이션**: 로드 시 평문 `password`/`adminPassword`가 있으면 해시로 바꾸고 즉시 저장(탈퇴 계정의 빈 문자열은 빈 해시 유지). 문자열 OTP·만료 없는 세션도 함께 마이그레이션.

## 28-51-02 · 로그인 잠금 + OTP 만료·시도 제한 [반영]

- `LOGIN_MAX_FAILS = 5`, `LOGIN_LOCK_MS = 15분`. 키 = 역할+식별자(관리자는 `admin:admin`), 스냅샷 `loginFails`. 실패 메시지에 "남은 시도 n회", 5회째 "15분간 로그인이 잠겼습니다", 잠금 중에는 맞는 비밀번호도 "N분 후 다시 시도" 거부. 성공·해제 시 초기화. `lockRemainingMs(role, id, now)`. `login(..., now)` 주입.
- OTP `{ code, issuedAt, attempts }`: `OTP_TTL_MS = 5분` 경과 시 폐기 + "만료 — 다시 가입", 오답마다 남은 시도 안내, `OTP_MAX_ATTEMPTS = 5` 초과 시 폐기. `verifyOtp(..., now)` 주입.
- auth vitest 4건 추가(15→19, 전체 212→**218**): 해시 저장·뷰 제외·변경·탈퇴·구 스냅샷 마이그레이션 / 잠금·해제·카운트 초기화·관리자 / OTP 만료·시도 초과 / 세션 만료. (초안 OTP 만료 테스트는 발급 시각과 기준 시각의 ms 차이로 1ms 여유가 부족해 실패 → 5초 여유로 정정. 기존 세션 `toEqual`은 만료 필드 추가로 `toMatchObject`로.)

## 28-51-03 · 세션 만료 [반영]

- `AuthSession.issuedAt/expiresAt`, `SESSION_TTL_MS`(고객·파트너 24h, 관리자 8h). `sessionFor(role, now)`: 만료면 세션 제거 + 게이트 안내 "세션이 만료되어 다시 로그인해 주세요" + 저장. 관리자 게이트에도 `[data-gate-notice]` 추가(기존엔 고객·파트너 게이트만). 마이페이지 "로그인 유지 … 까지 (이후 자동 로그아웃)"(`[data-session-expiry]`).

## 28-51-04 · e2e + 실측 [반영]

- e2e 3단계 추가 + 1단계 개명(116→**119**): 5회 오답 → 잠금 안내 / 잠금 중 정답 거부 / 저장소에 평문 없음 + `passwordHash`·`adminPasswordHash` 존재 → 저장소의 `lockedUntil`을 과거로 조정·새로고침 → "잠금 해제 후 새 비밀번호로 재로그인" / 관리자 세션 `expiresAt`을 과거로 조정·새로고침 → 게이트 + 만료 안내.
- 실측 `capture-28-52.mjs`: OTP 오답 남은 시도, 마이페이지 로그인 유지, 3회·5회 실패 메시지, 잠금 중 정답 거부, 저장소 발췌(해시·`loginFails`·빈 `otps`), 관리자 세션 발급·만료 시각(8h), 만료 후 게이트 안내, 모바일 가로 스크롤 없음.
