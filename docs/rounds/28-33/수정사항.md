# 28-33 수정사항 (Claude) — 내 계정 연결 라운드

기반: `28-32` 복사본(스크래치 wf28-33)에서 작업. 28-32 감사 4건 전부 반영.
로그인을 형식이 아니라 실질로: **요청이 계정에 묶이고, 고객 앱은 내 데이터만 보여준다.**

## 28-32-01 · 요청-계정 연결 [반영]

- `RepairRequest.customerId?`(계정 ID) — 위저드 제출 시 고객 세션의 accountId 탑재. 스냅샷 요소 검증(빈 문자열 거부) + 도메인 테스트 1건(탑재·왕복·손상 거부) → vitest 172→**173**.
- 고객 홈: 목록·지표(견적 대기/결정할 견적/진행 중/완료) 전부 **내 요청 기준**으로 전환. 견적함(pending/decided)도 동일. 계정 연결이 없는 시드·구 데이터는 고객 앱에서 숨김(파트너 일감·관리자 전체 조회는 역할 특성상 그대로).

## 28-32-02 · 위저드 이름 자동화 [반영]

- 작업 올리기 1단계에서 이름 입력 제거 — 로그인한 고객 이름 자동 사용(등록 확인 단계에 표기). 검증 문구 "지역/요청 내용을 모두 입력하세요"로 정리.

## 28-32-03 · 파트너 가입 업체명 프로필 시드 [반영]

- 파트너 가입 인증 완료 시 프로필이 비어 있으면 가입 업체명으로 기본 프로필 자동 시드 — 고객 업체 카드에 즉시 실명("반듯설비") 노출.

## 28-32-04 · e2e + 실측 [반영]

- e2e: 위저드 이름 필드 제거 반영, 업체 상세 스텝을 실명 노출 확인으로 강화, "내 요청만 표시(계정 미연결 시드 숨김)" 1단계 추가(41→**42**). 전 여정 무회귀.
- 실측: 위저드 이름 필드 없음 true, 새 계정 홈에서 시드 숨김·빈 상태 안내 true. 스크린샷 2종.
