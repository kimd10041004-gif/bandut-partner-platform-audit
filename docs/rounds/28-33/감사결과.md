## 상 (High)

### 28-33-01 · 계정 운영 도메인 부재
→ 요구: `AuthService`에
- `changePassword(role, current, next)`: 현재 비밀번호 불일치 거부, 새 비밀번호 8자 규칙, 관리자도 지원(시드 비밀번호 교체).
- `listAccounts()`: 관리자용 계정 목록(비밀번호 제외한 안전한 뷰).
- `setSuspended(accountId, suspended)`: **정지된 계정은 로그인 거부**("정지된 계정입니다 — 고객센터로 문의"), 정지 시 해당 역할의 활성 세션 즉시 종료. 저장소 왕복 + **도메인 테스트 필수**.

### 28-33-02 · 고객·파트너 마이페이지 (시안 "마이페이지")
→ 요구: 공용 `MyAccount` — 내 정보(이름·휴대폰·가입일, 파트너는 사업자등록번호·인증 상태) + 비밀번호 변경 폼. 고객 앱에 "마이" 탭 신설, 파트너는 기존 "마이" 탭(프로필) 상단에 배치.

### 28-33-03 · 관리자 회원 관리 (시안 4)
→ 요구: 관리자 "회원" 탭 — 계정 테이블(역할 필·이름·휴대폰·사업자번호·인증·가입일·상태) + 정지/해제 액션, 상단 지표(고객 수·파트너 수·정지 수).
