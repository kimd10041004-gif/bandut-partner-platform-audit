# 28-17 수정사항 — 28-16 감사 4개 항목 전부 처리 (홈페이지 개통 라운드)

작업 방식: 기존 규칙 그대로 — 28-1~28-16은 일절 수정하지 않고 스크래치 복사본(`scratchpad/wf28-17`)에서 수정 후 `28-17` 스냅샷 생성. 사용자 지시 "메인은 홈페이지라고"(홈페이지 시안 5장) 반영 라운드.

## 항목별 수정 내용

### 28-16-01 [상] 퍼블릭 홈페이지 메인 → 신규 구현 (`features/landing/Landing.tsx`)
- 앱 최초 진입 = 랜딩 홈페이지: 히어로("집수리, 비교하고 맡기세요." 대형 타이포 clamp 30~46px, 네이비 그라데이션) + CTA(작업 올리기/서비스 둘러보기) + 신뢰 배지 4종 + **실데이터 지표**(누적 요청·완료 수리·낙찰률 — 가짜 마케팅 숫자 대신 플랫폼 실측값).
- 카테고리 그리드("어떤 작업이 필요하세요?") 13종 — 선택 시 위저드에 카테고리 사전 선택 진입(`app/entry.ts` 전달 모듈).
- "간편한 4단계" 안내, 서비스 카드 3종(주거 케어/스마트홈 IoT/에어비앤비 세팅 — 시안 카피·그라데이션 3색), 하단 CTA 밴드.
- 헤더 브랜드(로고+제목)가 버튼이 되어 클릭 시 홈 복귀. 역할 스위처 선택 시 앱 진입. 사진 에셋 없이 토큰·그라데이션만 사용(다크 모드 동작).

### 28-16-02 [상] 작업 올리기 4단계 위저드 → 재구성 (`CustomerRequest.tsx`)
- ①작업 내용(카테고리 그리드+이름·지역·요청 내용) ②일정 선택(방문일+**오전/오후 세그먼트**+입찰 마감) ③희망 예산(범위 라디오 6종 또는 직접 입력, "예산은 참고용" 안내 — 시안 문구) ④등록 확인(요약 → "입찰 시작하기").
- 알약형 스텝 표시(now=브랜드/done=green), 단계별 검증, 이전/다음.
- 도메인 확장: `desiredTime?('오전'|'오후')`·`budgetRange?(string)` — addRequest·스냅샷 검증 + 왕복 테스트 2개(142/142). 하위 호환(필드 없는 구 데이터 통과).

### 28-16-03 [중] 카테고리 시안 정렬 → 확장
- `RepairCategory`를 시안 그리드의 상위 집합 13종으로 확장(장판·수전·배수·문·도어락·방충망·목공·스마트홈 추가, 기존 멤버 유지로 데이터 호환). CATEGORIES 노출 순서는 시안 순. 위저드·일감 필터·랜딩 그리드에 자동 반영.

### 28-16-04 [중] 신규 필드 전 역할 노출 → 수정
- 파트너 일감·입찰 카드: 희망일 뒤 시간대, 예산 범위 표시. 고객 거래 상세·관리자 거래 상세: 희망 시간대·희망 예산 표시(있을 때만).
