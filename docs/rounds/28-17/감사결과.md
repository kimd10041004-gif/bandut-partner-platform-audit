## 상 (High)

### 28-17-01 · 리뷰 도메인 부재 — 신뢰 지표의 근거가 없음
시안 전반에서 평점(★4.9, 후기 수)이 신뢰의 근거인데, 현재 도메인에는 리뷰 개념이 없다.
→ 요구: `Review { requestId, rating(1~5 정수), text, createdDate }` — `writeReview()`는 **completed/settled 상태에서만**, 요청당 1건(중복 시 오류), rating 범위 검증. `reviewFor(requestId)`·`reviewStats()`(건수·평균, 없으면 null). 스냅샷 `reviews?` 하위 호환 + 요소 검증 + **도메인 테스트 필수**.

### 28-17-02 · 고객이 리뷰를 쓸 곳이 없음 (시안 5 "리뷰 작성")
→ 요구: 고객 거래 상세 — 완료·정산 거래에 리뷰 작성 카드(별점 1~5 선택 + 한 줄 후기), 작성 후에는 작성된 리뷰 표시(별점·내용·작성일). 타임라인에 "리뷰 작성" 이벤트 추가(리뷰 있을 때만).

### 28-17-03 · 파트너가 평판을 볼 수 없음 (시안 2 "고객 리뷰·평균 평점")
→ 요구: 마이 탭 입찰 성과 카드에 평균 평점(★x.x·건수) 병기 + "고객 리뷰" 카드(최근 리뷰 목록: 별점·내용·요청 정보). 파트너 대시보드 지표에는 넣지 않는다(지표 4개 유지 — 밀도 원칙).

## 중 (Medium)

### 28-17-04 · 관리자 리뷰 관리 부재 (시안 4 메뉴 "리뷰/평점 관리")
→ 요구: 관리자 역할에 "리뷰" 탭 추가 — 전체 리뷰 표(요청·고객·별점·내용·작성일) + 평균 평점 요약. ROLES 구조 덕에 탭 1개 추가로 끝나는지 확인(틀의 시험).

### 28-17-05 · 홈페이지 신뢰 지표에 만족도 없음 (시안 랜딩 "고객 만족도 4.9/5.0")
→ 요구: 랜딩 히어로 지표에 "평균 만족도"(실데이터 평균, 리뷰 없으면 "—") 추가.
