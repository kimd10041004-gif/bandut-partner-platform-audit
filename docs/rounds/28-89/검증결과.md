## 4. e2e로 확인한 사람의 동선

**여정(로컬 모드)** — `npm run e2e`에 8단계가 늘었다:

- `열람 관리자 로그인 → 이름·등급 태그` · `열람 등급: 읽기 전용 배너 + 셸 표시 (28-89-A)`
- `열람 등급: 관리자 목록은 보이지만 추가 폼·제거 버튼이 없다` · `배치 저장·되돌리기 비활성 + 등급 안내`
- `열람 등급: 백업 내보내기·되돌리기 비활성` · `소유자가 열람 관리자 제거 → 1행`

**서버 모드** — `npm run e2e:server`에 7단계. 여기서는 **화면이 아니라 API를 직접** 친다:

- `C: 소유자 세션의 등급 태그 + sessions.grade = owner` (DB 행을 직접 조회)
- `C: 열람 관리자 추가 → 서버 auth_state 에 있고 해시는 s256$ (28-89-A)`
- `viewer1: 서버 로그인 200 + 세션 등급 viewer`
- `viewer1: 목록은 200, 정지·관리자 추가는 403 — 서버가 막는다 (28-89-A)`
- `viewer1: 스냅샷 PUT 은 403 이고 rev 가 그대로다 (28-89-A)` — 화면을 우회해도 막힌다
- `viewer1: 스냅샷 GET 은 200 — 보기는 된다`
- `소유자가 등급 변경 → 바뀐 관리자의 옛 토큰은 401 (28-89-A)`
- `매니저로 재로그인: 등급 manager, 관리자 추가·파기는 여전히 403`

마지막 둘이 이 라운드에서 가장 중요한 검사다: **등급이 바뀌면 옛 토큰이 죽고**, 매니저로 올라가도
관리자 관리·파기는 여전히 서버가 막는다.

## 7. #244 리뷰 반영 — 열람 등급 차단이 마우스에게만 참이었다

Copilot이 정확히 짚었다: 열람 등급 화면을 `.admin-readonly button { pointer-events: none }`
**CSS 하나**로 막았는데, `pointer-events: none`은 **포커스와 키보드를 막지 않는다**.
Tab으로 옮겨 Enter/Space를 누르면 `onClick`이 그대로 돌았다.

서버 모드에서는 그 클릭이 403으로 끝나지만 **로컬 모드에는 막아 줄 서버가 없다** — 그리고
§6이 확인했듯 **프로덕션이 지금 로컬 모드다.** 즉 지금 라이브에서 참인 구멍이었다.

**수정**: `src/app/adminReadOnly.ts`의 `isBlockedForViewer()`가 "상태를 바꾸는 조작"인지 판정하고
(`button`·`select`·체크박스/라디오/파일 입력과 그것을 감싼 `label`, `.filter-group button`·`.link-btn`·
`[data-viewer-ok]`는 제외), `AdminGradeShell`이 **캡처 단계**에서 `click`·`keydown`·`change`·`submit`을
막는다. CSS는 이제 "막는 장치"가 아니라 **"막혔다는 표시"**(opacity·cursor)다.

**수정 전 실패 인용** (`npm run e2e`, 수정 파일 3개만 되돌려 실행):

```
FAIL  열람 등급: 키보드(Space)로도 카테고리 노출이 바뀌지 않는다 (#244 리뷰)
PASS  열람 등급 화면에도 정지 버튼은 그려진다 — 눌리지 않을 뿐이다
FAIL  열람 등급: 키보드(Enter)로도 계정을 정지시킬 수 없다 (#244 리뷰)
PASS  열람 등급: 탭 이동·기록 열람은 그대로 된다
E2E-JOURNEY FAIL: 2건
```

수정 뒤 `E2E-JOURNEY OK`. **그 사이 "탭 이동·기록 열람은 그대로 된다"가 계속 PASS인 것이 중요하다** —
막기만 하고 못 쓰게 만들면 열람 등급이 쓸모없어진다.

단위 테스트가 아니라 e2e로 고정한 이유: 이것은 **브라우저 이벤트 동작**이고, 이 저장소에는 DOM 테스트
환경이 없다(vitest는 `node`). 없는 환경을 새로 들이는 것보다 이미 있는 Playwright에서 **실제 키보드로**
누르는 편이 재는 것에 가깝다.

**여전히 화면의 차단이다.** 콘솔로 도메인 메서드를 직접 부르는 것은 막지 못한다 — 실제 경계는
도메인·서버이고, 로컬 모드에는 그 서버가 없다(§6의 표와 같은 이야기).

재검증: `check` 555 passed · `e2e` OK · `visual-check` OK · `audit` 0 · `e2e:server` ×2 각 59 passed.
