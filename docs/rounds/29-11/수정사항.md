# 29-11 수정사항 — 인증번호를 아무 데서나 내주지 않는다

새 명세(업체 포트폴리오·상담 기능 설계, 2026-09-10)의 3절과 12절이 먼저 확인하라고 지목한 두 가지를
이 라운드에서 처리한다. 화면 기능은 아직 손대지 않았다.

## 1. 인증번호가 조건 없이 응답에 실려 있었다

`server/handlers/auth.ts`가 가입 응답에 발급된 인증번호를 그대로 담고 있었다.

```ts
// 시연: OTP를 응답으로 — SMS 연동 시 여기서 뺀다
out.result = { account: view, otp: r.otp }
```

환경을 보는 조건이 하나도 없다. 28-31에서 문자 발송이 없어 그렇게 두었고, 주석이 "SMS 연동 시 여기서
뺀다"고 적어 두었지만 그 자리가 만들어진 적은 없다.

**이게 왜 나쁜가.** 남의 번호를 적어 넣어도 서버가 그 번호의 인증번호를 되돌려 준다. 그러면 휴대폰
인증이 "이 번호를 쥔 사람인가"를 확인하지 못한다. 명세 3절이 "휴대폰 인증은 해당 번호를 제어한다는
확인"이라고 쓴 것이 성립하지 않는다.

## 2. 두 개의 문으로 나눴다 — `server/authSafety.ts`

| 함수 | 묻는 것 |
|---|---|
| `devOtpAllowed` | 개발용 인증번호를 화면·응답에 **보여도 되는가** |
| `smsConfigured` | 진짜 문자를 **보낼 수 있는가** |

```
운영(VERCEL_ENV=production)   언제나 false — 플래그가 새어 들어와도 첫 줄에서 끝난다
프리뷰                        AUTH_DEV_OTP=on 을 명시적으로 켠 경우에만
로컬·CI                       연다 (배포가 아니다. 게이트가 이 값으로 가입 여정을 돈다)
```

둘 다 아니면 **가입을 받지 않는다**. 받아 봐야 사용자는 인증번호를 얻을 수 없고 미인증 계정만 쌓인다.
명세 3절의 "운영 문자 미설정 → 실패 처리, 개발용 응답으로 대체 금지"가 그 말이다.

플래그를 켜지 않은 프리뷰는 운영과 똑같이 막힌다. 전환 전 마지막 점검을 프리뷰에서 그대로 해 볼 수
있게 하려는 것이다.

`smsConfigured`는 `SMS_PROVIDER`·`SMS_API_KEY`·`SMS_SENDER` 셋을 모두 요구한다. 발송 코드는 아직
없으므로 지금 운영에서 이 함수가 true를 주는 일은 없어야 한다 — 값만 넣고 발송 코드가 없으면 가입이
인증번호 없이 통과해 버린다.

**고객 가입 코드는 그대로 둔다.** 실제 문자 인증이 검증된 뒤에 뗀다.

## 3. 프리뷰가 어느 DB를 보는지 확인할 방법 — `server/dbFingerprint.ts`

명세 12절의 14단계 왕복 검증은 계정을 만든다. 그 프리뷰가 운영 DB를 보고 있으면 테스트 계정이 운영
데이터에 섞인다. 그래서 분리 확인 전에는 하지 않기로 했는데, **확인할 방법 자체가 없었다.**

29-5의 `resolveDatabaseUrl`이 프리뷰 전용 이름(`DATABASE_URL_PREVIEW`)을 이미 고른다. 남은 것은
골라진 결과를 사람이 보게 하는 일이다.

```
환경          preview
접속 호스트    ep-… .neon.tech        ← Neon 은 브랜치마다 다르다
DB 이름       neondb
운영과 분리    분리됨 / 분리되지 않음
```

호스트와 DB 이름만 만든다. 사용자·비밀번호·쿼리 문자열은 파싱 단계에서 버리므로 실수로 로그에 남을
수도 없다. 명세 12절의 "비밀번호가 포함된 전체 연결 문자열은 기록하지 않는다"를 구조로 지킨다.

`/admin/diagnostics`에서 본다. 관리자 로그인과 열람 등급을 서버가 확인하므로 주소를 알아도 로그인
없이는 아무것도 나오지 않는다 — 명세 12절의 "공개 주소에 진단 정보를 노출하지 않는다"다.

## 하지 않은 것

- **문자 발송 연동** — 다음 선행 작업이다. 이 라운드는 "없으면 막는다"까지다.
- **비밀번호 복구** — 화면·API 모두 다음 라운드다. 같은 두 문을 그때 함께 건다.
- **고객 가입 코드 해제** — 실제 문자 인증 검증 뒤로 미뤘다.
