## 1. 고치기 전에 실패를 봤다

새 통합 단언을 먼저 넣고 `server/marketplaceApi.ts`를 고치기 전 상태로 되돌려 돌렸다.

```
× 업체 찾기는 로그인 없이 열리고 승인된 업체만 나온다 (29-13)
  AssertionError: {"error":"로그인이 필요합니다."}: expected 401 to be 200
```

그 단언이 보는 것 넷.

```
✓ 토큰 없이 목록이 200 이다
✓ 승인된 업체는 나오고 미승인 업체는 안 나온다
✓ 후기가 없으면 rating 이 null 이다 — 0.0 을 만들지 않는다
✓ 분야 필터가 실제로 좁힌다 (다른 분야로 조회하면 0건)
✓ 상세도 토큰 없이 200 이고, 미승인 업체는 주소를 알아도 404
```
