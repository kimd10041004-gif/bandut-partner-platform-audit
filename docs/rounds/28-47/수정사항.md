# 28-47 수정사항 (Claude) — 지역·분야 매칭 라운드

기반: `28-46` 복사본(스크래치 wf28-47)에서 작업. 28-46 감사 4건 전부 반영.

## 28-46-01 · 매칭 도메인 [반영]

- `parseTokens(raw)`(쉼표·줄바꿈 구분, 공백 제거, 중복 제거) / `profileMatch(profile, request)` — 전문 분야에 요청 카테고리가 있고, 지역 토큰 중 하나가 요청 지역에 포함(지역 비면 통과, 분야 비면 매칭 없음). 카테고리 이름에 가운뎃점(`수전·배수`)이 있어 `·`는 구분자로 쓰지 않는다.
- `addRequest` → 매칭 프로필 보유 파트너 전원에게 "내 지역·분야 새 일감" 알림(계정 범위). `matchedRequests(partnerId, today)` — 낙찰 전·마감 전·매칭. `updateProfile`은 분야 토큰이 카테고리 목록에 없으면 거부("알 수 없는 전문 분야: …"). `DEFAULT_PARTNER_PROFILE`의 분야·지역은 비움(고객 카드는 "집수리 전반/서울 전역" 폴백).
- 도메인 테스트 2건 → vitest 201→**203**(기존 partnerSummary 테스트의 `욕실·누수` 입력을 `욕실, 누수`로 정정).

## 28-46-02 · 프로필 폼 구조화 [반영]

- 마이 탭 프로필: 전문 분야 **카테고리 필 다중 선택**(`.specialty-pick`, 저장은 쉼표 문자열), 서비스 지역 쉼표 입력(`aria-label="서비스 지역"`) + 안내.

## 28-46-03 · 일감 탭 맞춤 필터 + 대시보드 [반영]

- 일감 탭 "내 지역·분야만" 체크(`aria-label`, 분야 설정 시 기본 켜짐, 미설정 시 비활성 + 안내 툴팁) + 카드 제목 "맞춤" 태그(`data-matched`). 대시보드 "맞춤 일감 n건 / 전체 m".

## 28-46-04 · e2e + 실측 [반영]

- e2e 5단계 추가(96→**101**): 프로필 저장(욕실·누수·서울) → 맞춤 토글 기본 켜짐·전기 건 제외 → 토글 해제 전체 → 고객 서울 욕실 요청 등록 → 파트너 벨 +1 → 패널 "내 지역·분야 새 일감". 첫 실행 실패 2건은 입찰 폼 select에 전체 후보 텍스트가 들어 있어 본문 텍스트 판정이 오염된 것 → 카드 제목(h3) 기준으로 정정, 그리고 e2e 시점에 서울·욕실 열린 요청이 없어 누수 분야를 함께 선택.
- 실측 2장. 실측 중 프로필 안내문에 감사 번호가 노출돼 문구 정리.
