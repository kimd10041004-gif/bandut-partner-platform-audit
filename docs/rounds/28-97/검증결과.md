## 4. e2e 여정에 더한 단언

```
PASS  영수증 주문번호 BD-…-final-…
PASS  관리자 정산 내역: 총액 352,000 − 환불 0 − 수수료 10,560 = 341,440
PASS  부분 환불 등록 → 환불 대기 22,000
PASS  환불 대기 중에는 정산 확정 차단
PASS  관리자 환불 완료 처리
PASS  환불 반영 재산정: 수수료 9,900 · 지급액 320,100
```

총액 352,000원(275,000 + 추가 공사 77,000)에 계약 수수료 3%. 환불 22,000원이 완료되자 수수료가 10,560 → 9,900원으로,
지급액이 341,440 → 320,100원으로 다시 산정됐다. 기존 지급·원장 단계는 그대로 통과한다.
