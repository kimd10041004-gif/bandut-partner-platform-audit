### 28-83-01 구현 중 발견한 것 — 그대로 적는다

처음 쓴 유도 정규식(`\(([^)]*)\)`)은 **여섯 중 넷만** 잡았다. `today: string = todayUTC()`의 괄호가
인자 목록을 끊어 `partnerSummary`·`partnerCancelCount`가 빠졌다. 그 상태로도 하한 검사는 **통과한다** —
유도가 덜 잡으면 "빠진 것 없음"이 되기 때문이다. 즉 고치려던 실패로 조용히 돌아가 있었다.

괄호를 세는 방식으로 바꾸고, **유도 완전성 자체를 테스트로 고정**했다:

```
유도(공개): ['allReviews', 'bidStats', 'partnerCancelCount', 'partnerSummary', 'reviewStats', 'statusCounts']
유도 전체: 7 / 파일의 excludeSeeded?: boolean 개수: 7
```
