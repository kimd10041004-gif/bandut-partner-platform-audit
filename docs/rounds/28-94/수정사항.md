# 28-94 수정사항 — 상세 주소·연락처 접수 · 낙찰 전 파트너 가림 (참고 v12 대조 4)

`../28-90/참고_v12_대조.md` "더할 것" 4번. 참고 시안은 요청에 **상세 주소·연락처**를 싣고(`orderSchema`: 주소 5자 이상, 연락처
`01[016789]…`), 파트너에게는 **선택된(낙찰) 파트너가 아니면** `address`·`phone`·`answers`·`customer_id`를 빼고 사진도 열지 않는다
(`lib/service.ts` `view()`, `photoPermission`). 28-93까지 우리 요청에는 주소·연락처 자체가 없었고, 고객 이름·현장 사진은 입찰 전
모든 파트너에게 그대로 보였다.

## A. 도메인 (`types.ts` · `platform.ts`)

- `RepairRequest.address?`(5~200자, 공백 정리)·`phone?`(숫자만, `010` + 7~8자리). `addRequest`가 `normalizeAddress`·
  `normalizeRequestPhone`로 정리하고 위반은 `PlatformError`. 없으면 구 데이터와 같은 모양(선택 필드).
- **`requestForPartner(r, partnerId)`**: `r.acceptedPartnerId === partnerId`면 그대로, 아니면 `PARTNER_PRIVATE_KEYS`
  (`address`·`phone`·`photos`)를 빼고 `customerName`을 `maskName`(정*훈, 이*, 남**수)으로. 낙찰 판정은 28-42-01의
  `acceptedPartnerId` 하나다 — 낙찰 전·미낙찰(lost)·구 데이터 전부 가려진다.
- 참고안과 다른 점: 참고안은 `answers`(안전 답변)도 뺀다. 우리 `answers`는 분야 질문의 답(곰팡이 유무 같은 견적 정보)이라
  파트너에게 남긴다. 안전 답변(`safety`)은 28-93부터 관리자 검토 카드에만 보인다.
- 스냅샷 검증: `address`(문자열·5자 이상)·`phone`(010 규칙).
- 반출: **본인 반출**(`exportCustomerData`)에는 주소·연락처를 담는다(정보주체). 그 자체 검사(`assertNoRealIdentifiers`)가 계정
  연락처 목록(`extraNames`, 하이픈 형태)과 요청의 본인 번호(숫자만)를 같은 번호로 보게 했다 — 이걸 놓쳐 e2e의 "내 데이터
  내보내기"가 던졌다(검증결과 §2). 파트너 반출·가명본에는 넣지 않는다(28-61-02 허용 목록 방식이라 기본이 제외).

## B. 화면

- **위저드 1단계**: 지역 아래 "상세 주소 (필수, 5자 이상) — 낙찰된 파트너에게만 보입니다"(`aria-label="상세 주소"`)와
  "연락처"(`aria-label="요청 연락처"`, 계정 번호로 채워지고 고칠 수 있다). 다음으로 갈 때 같은 규칙으로 막는다. 등록 확인에 주소 표시.
- **파트너 일감·입찰**(`Jobs.tsx`): 목록을 `requestForPartner`로 통과시킨다 — 사진 띠 대신 `[data-private-note]` "현장 사진·상세
  주소·연락처는 낙찰 뒤 내 작업에서 열립니다", 이름은 가림. 키워드 검색도 가려진 이름을 본다.
- **파트너 내 작업**(`Work.tsx`): 같은 함수를 통과시키되 낙찰 건은 전부 열린다 — `[data-private-details]` "방문지 … · 연락처 010-…"
  + 현장 사진. 미낙찰(lost) 행은 가려진 채다. **대시보드** 오늘·다가오는 일정도 같은 함수(낙찰 건이라 실명).
- **고객 홈** 거래 상세·**관리자 거래 상세**: 주소·연락처 표시(본인·관리자는 전부 본다).
- `fmtPhone`은 `src/ui/format.ts`로 올렸다(마이페이지가 갖고 있던 것).

## C. 하지 않은 것

- 낙찰 전 요청 수정 폼(28-53)에 주소·연락처 편집은 없다 — 다시 올리거나 채팅으로 알린다. 다음 라운드에서 필요하면 `updateRequest`에
  넣는다.
- 참고안의 사진 만료(`expires_at`)·서명 URL은 저장 방식이 다르다(우리는 스냅샷 안 데이터 URL, 28-49 보관 정책).
- 파트너 반출 CSV의 `region`은 그대로 시·군·구까지다(주소가 아니다).
