## 항목별 수정 내용

### 28-7-01 [상] 시안 디자인 언어 미반영 → 수정
- `styles.css` 전면 재작성: 디자인 토큰(네이비 `#0e2a47`, 브랜드 그린 `#15695a`, 상태 컬러 5종) 기반 시스템.
- 네이비 상단 헤더바(로고 마크 + 타이틀), 스티키 탭 바, 카드 그림자/라운드, Pretendard 폰트(CDN).
- **상태 칩 컬러 가이드** (시안 하단 가이드 기준): 입찰 가능/입찰 중=파랑, 낙찰/작업 완료=초록, 방문 예정=브랜드 그린, 시공 중=주황, 미낙찰=빨강, 정산 완료/취소=회색 — `StatusChip` 공용 컴포넌트로 통일.
- 버튼 위계: primary(브랜드) / btn-secondary(외곽선) / btn-danger(미낙찰 등).

### 28-7-02 [상] 대시보드 지표 타일 → 수정
- 시안 구성 그대로 4지표 타일 그리드: **오늘의 작업 / 입찰 가능 / 진행 중 / 정산 예정 금액** (금액 타일은 브랜드 액센트).

### 28-7-03 [상] 일감 카드 → 입찰 폼 동선 → 수정
- 입찰 대상 선택 상태를 탭 레벨로 승격. 일감 카드의 **"이 일감에 입찰"**(입찰 가능) / **"제안 수정"**(입찰 중) 버튼이 폼 대상과 연동되고 폼으로 부드럽게 스크롤.

### 28-7-04 [중] D-day 시각 신호 → 수정
- `Dday` 컴포넌트: 기본 파랑, **D-2 이하 주황(임박), 마감 빨강** — 예산은 굵게 표시.

### 28-7-05 [중] 폼·표 반응형 → 수정
