# 28-8 감사결과 (GPT 역할 — Claude 세션 대리 수행)

감사 범위: `28-8` 전체 + 기획 시안의 미반영 요소 대조. 사전 확인: `tsc --noEmit` 0 오류, vitest 115/115, node --test 7/7, Playwright 렌더링 검증 통과, Vercel 배포 그린. 28-7 감사 5건(디자인 언어·지표 타일·입찰 동선·D-day·반응형) 전부 수정 확인됨.

디자인 기반이 갖춰졌으므로, 이번 감사는 시안에 명시돼 있으나 아직 없는 **파트너 업무 기능**을 항목화한다.

---

## 중 (Medium — 시안 명시 기능)

### 28-8-01 · 내 작업 카드에 진행 단계 시각화 부재
시안(파트너 PC 7번 "작업 수행 상세")은 **작업 전 → 작업 시작 → 작업 중 → 작업 완료 → 고객 확인** 스텝퍼로 현재 단계를 한눈에 보여준다. 현 구현은 상태 칩 하나뿐이라 전체 여정에서 어디쯤인지 읽히지 않는다.
→ 요구: 낙찰 → 방문 예정 → 시공 중 → 작업 완료 → 정산 완료 5단계 스텝퍼를 내 작업 카드에 표시 (완료 단계 채움, 현재 단계 강조; 미낙찰/취소 카드는 제외).

### 28-8-02 · 작업 체크리스트 부재
시안(파트너 모바일 5번 "낙찰/작업 상세")에 **작업 체크리스트**(현장 방문 및 실측 / 자재 수급 / 작업 일정 확정)가 명시돼 있다. 현 구현에는 없다.
→ 요구: 요청별 체크리스트(고정 3항목) 토글 + 영속화. 낙찰 이후(진행 카드)에서 조작 가능, 스냅샷 하위 호환(신규 선택 필드) 유지, 도메인 레벨 테스트.

### 28-8-03 · 모바일 하단 탭바 부재 (동선 효율)
시안 모바일은 하단 5탭 내비게이션이 기본이다. 현 구현의 상단 탭은 좁은 화면에서 가로 스크롤이 생겨 엄지 동선이 나쁘다.
→ 요구: 좁은 화면(≤640px)에서 탭 바를 하단 고정 바로 전환 (본문 하단 여백 확보 포함).

## 하 (Low)

### 28-8-04 · 파트너 프로필(마이) 부재
시안의 '마이/프로필 설정'(업체명·전문 분야·서비스 지역·소개)이 없다. 정산·입찰 화면의 신뢰 요소이기도 하다.
→ 요구: '마이' 탭 — 프로필 등록/수정(업체명 필수), 영속화 + 백업 포함, 도메인 레벨 검증 테스트.
