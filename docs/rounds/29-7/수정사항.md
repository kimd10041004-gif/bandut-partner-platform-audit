# 29-7 수정사항 — 시안과 같은 사진이 같은 자리에

## 왜 이 라운드가 생겼나

29-6 이 화면 안의 이미지 404 를 없앴다. 없앤 방법이 **시안이 부르는 파일 이름을 우리 브랜드
파일 이름으로 바꿔 다는 것**이었다. 404 는 사라졌지만 사진 자체가 다른 것이 됐다.

29-6 의 시안 대조가 그것을 드러냈다. 글은 한 줄 빼고 같은데 이미지 목록이 전부 달랐고,
요청 화면은 **장수까지 어긋났다** — 시안은 같은 사진을 두 자리에 쓰는데 29-6 이 자리마다 다른
파일을 골라 서로 다른 두 장이 됐다.

두 갈래를 사장님께 물었고 **"시안과 똑같이 보이게"** 를 골랐다.

## 1. 이름을 바꾸는 대신 파일을 채운다

시안의 파일을 시안이 부르는 경로 그대로 저장소에 넣었다. 그러면 화면 코드를 v17 원본으로
되돌릴 수 있다 — 원본과 대조할 수 있어야 한다는 29-1 규칙에도 더 맞는다.

| 화면 | 29-6 (바꿔 달았던 것) | 29-7 (되돌린 것) |
|---|---|---|
| `shell.tsx` 로고 | `/brand/logo-mark.png` | `/brand/logo.png` |
| `home.tsx` · `info.tsx` 메인 | `/brand/hero-main.jpg` | `/home-interior.webp` |
| `brand-films.tsx` | `/brand/svc-care.jpg` | `/brand/inspection.webp` |
| `presentation-view.tsx` | `/brand/svc-bnb.jpg` | `/brand/inspection.webp` |
| `dashboard.tsx` | `/brand/svc-iot.jpg` | `/partner-background.webp` |

`presentation-view` 와 `brand-films` 가 다시 **같은 파일**을 가리킨다. 시안이 그렇다.

## 2. 받아 오는 것도 기계가 한다

개발 컨테이너에서는 시안 주소로 나갈 수 없다(프록시). `fetch-reference-assets` 워크플로가
Actions 에서 받아 브랜치에 커밋한다.

**받은 것이 정말 이미지인지 확인한 뒤에만 저장한다.** MIME 이 `image/*` 인지(SVG 는 내용에
`<svg` 가 있는지), 크기 하한을 넘는지. 하나라도 어긋나면 **아무것도 커밋하지 않는다** —
로그인 페이지 HTML 을 이미지라고 저장소에 넣는 일이 없도록.

받은 것:

```
/brand/logo.png            image/png    903,413 바이트
/home-interior.webp        image/webp   168,830
/brand/inspection.webp     image/webp    14,846
/partner-background.webp   image/webp   205,270
/favicon.svg               svg              270
```

## 3. 가드 구멍 — 탭 아이콘이 모든 화면에서 404 였다

`app/layout.tsx` 가 `metadata.icons` 로 `/favicon.svg` 를 부르는데 그 파일이 저장소에 없었다.

**세 가지가 다 못 봤다.**

| 무엇 | 왜 못 봤나 |
|---|---|
| 29-6 단위 가드 | `src="/…"` 만 본다. `metadata.icons` 는 `src=` 가 아니라 그냥 문자열이다 |
| 29-6 배포 확인(화면 안) | `<img src>` 만 센다. 아이콘은 `<link rel="icon">` 이다 |
| 경로 36개 검사 | 우리가 목록에 적은 주소만 센다 |

그물을 확장자로 바꿨다. 따옴표 안에 `/…` 로 적힌 정적 파일이면 `src=` 든 아니든 전부 본다.

```
it("따옴표 안의 '/...' 정적 파일이 전부 public/ 안에 있다 — metadata.icons 같은 자리까지")
```

**넓힌 가드를 수정 전 코드에 먼저 돌렸다.** `/favicon.svg` 하나를 정확히 집어냈고, 그 뒤에
파일을 받았다.

## 4. 하지 않은 것

- **옛 브랜드 파일을 지우지 않았다.** `hero-main.jpg` · `logo-mark.png` · `svc-bnb.jpg` ·
  `svc-care.jpg` · `svc-iot.jpg` 는 지금 아무도 부르지 않는다. 지우는 것은 되돌리기 어려우니
  따로 정한다.
- **색·간격·글꼴은 견주지 않았다.** 이 라운드가 맞춘 것은 파일이다. 눈에 보이는 모양은
  사람이 봐야 한다.
- **"검토용 서비스" 문구는 그대로다.** 시안과 우리가 똑같이 갖고 있고, 프로덕션 전환 직전에
  걷는다(다섯 자리는 `docs/rounds/29-6/시안_대조.md` §5).
- 병합·프로덕션 전환은 사장님 승인 전에는 하지 않는다.
