# 28-54 수정사항 (Claude) — 보증·파트너 응답 라운드

기반: `28-53` 복사본(스크래치 wf28-54)에서 작업. 28-53 감사 4건 전부 반영.

## 28-53-01 · 보증 기간 [반영]

- `SiteSettings.warrantyDays`(기본 `WARRANTY_DEFAULT_DAYS = 90`), `updateSettings` 검증(정수 0~365), 스냅샷 검증. 구 스냅샷은 기본값 병합으로 90일.
- `warrantyStatus(requestId, today)`: 완료·정산 건에 `{ until(완료일 + 보증일), daysLeft, active(daysLeft ≥ 0) }`, 그 외 `undefined`. `fileClaim('as')`는 만료 후 "보증 기간이 지났습니다 (만료 …) — 유상 A/S는 파트너와 채팅으로 협의" 거부, 분쟁은 무관.
- 고객 거래 상세 A/S 카드 배지(`[data-warranty="active|expired"]`, "무상 A/S 보증 D-n · …까지" / "보증 만료 …"), 만료 시 접수 버튼 비활성. 관리자 설정 "A/S 보증 기간" 카드(`aria-label="보증 일수"`, "보증 저장").
- vitest 1건: 설정 검증(400·1.5 거부)·D-86·만료 경계(당일 유효, 익일 만료)·만료 후 A/S 거부·분쟁 허용·30일/365일 재계산·스냅샷 왕복·손상 거부.

## 28-53-02 · A/S·분쟁 파트너 답변 + 무응답 운영 큐 [반영]

- `Claim.partnerReply/repliedDate`. `replyClaim(claimId, partnerId, text, date)`: 낙찰 파트너만, 미해결만, 빈 답변 거부, 최신 답변으로 덮어쓰기, 고객·관리자 알림. `opsQueue.unansweredClaims`(`CLAIM_REPLY_SLA_DAYS = 2` 경과·답변 없음, 경과일 내림차순) + `counts.unansweredClaims`, 현황 조치 필요 그룹 `data-ops="unanswered"`.
- 파트너 내 작업 카드 `ClaimReplyBox`: 미해결 접수 상세 + "답변 없음 — 2일 안에 답변" 안내 + 입력(`aria-label="A/S 답변"`)·"답변 저장". 고객 거래 상세·관리자 A/S 탭 `[data-claim-reply]`(관리자는 "파트너 답변 없음" 태그).
- vitest 1건: 권한·빈 답변·SLA 경계(1일 0건, 2일 1건)·답변 후 0건·덮어쓰기·알림 2건·해결 후 거부·스냅샷.

## 28-53-03 · 리뷰 답글 [반영]

- `Review.reply/repliedDate`. `replyReview(requestId, partnerId, text, date)`: 리뷰 존재·그 작업의 파트너만·빈 답글 거부·수정 가능·고객 알림. 스냅샷 검증.
- 파트너 마이 탭 `ReviewReplyForm`(`aria-label="리뷰 답글"`, 답글 저장/수정), 고객 업체 카드 "↳ 업체 답글", 관리자 리뷰 탭 답글(`[data-review-reply]`).
- vitest 1건: 리뷰 없음·권한·빈 답글·수정·알림 2건·스냅샷 왕복·손상 거부.

- e2e 6단계 추가(124→**130**): 파트너 A/S 답변 저장 / 고객 거래 상세 답변 + 보증 배지 D-90 / 관리자 A/S 탭 답변 표시 / 파트너 리뷰 답글 저장 / 고객 업체 카드 답글 / 관리자 보증 60일 저장. (설정 탭에 카드가 하나 늘어 기존 저장 실패 배너 단계의 "첫 번째 저장 버튼" 선택자가 보증 저장을 누르게 됨 → "문구 저장"으로 명시.)
