→ 요구: 고객 수리 요청 탭을 4단계 위저드로 재구성(진행 표시, 이전/다음, 마지막 요약 확인). 도메인 확장: `desiredTime?('오전'|'오후')`·`budgetRange?(string)` — 스냅샷 하위 호환 + 검증 + 테스트. 홈 카테고리 그리드에서 위저드로 카테고리 사전 선택 전달.
