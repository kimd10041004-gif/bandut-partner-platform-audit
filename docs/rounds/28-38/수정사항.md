# 28-38 수정사항 (Claude) — 약관·개인정보 동의 라운드

기반: `28-37` 복사본(스크래치 wf28-38)에서 작업. 28-37 감사 4건 전부 반영.

## 28-37-01 · 약관 동의 도메인 [반영]

- `Account.consent: ConsentRecord { termsAt, privacyAt, marketing, marketingAt? }` — 가입 시 필수 동의 일시 기록. `register()` 입력에 `agreeTerms`·`agreePrivacy`(필수)·`marketing`(선택) 추가, 둘 중 하나라도 false면 "필수 약관(이용약관·개인정보 수집·이용)에 동의해 주세요"로 거부(이름·휴대폰·비밀번호 검증 다음, 파트너 유형 검증 앞).
- `setMarketingOptIn(role, on)` — 로그인한 고객·파트너만, 상태가 바뀔 때만 `marketingAt` 갱신·저장. 스냅샷 로드 시 `consent` 누락·형식 불량 계정은 초기화(기존 손상 처리 경로).
- 도메인 테스트 3건(필수 미동의 거부·일시 기록·마케팅 선택 / 동의·철회 왕복 / 손상 스냅샷 초기화) + 기존 `register` 호출 18곳에 동의 플래그 추가 → vitest 180→**184**(설정 테스트 1건 포함).

## 28-37-02 · 약관 본문 운영 설정(CMS) [반영]

- `SiteSettings.terms`·`privacy` 추가, 기본값 `DEFAULT_TERMS`(9조+부칙)·`DEFAULT_PRIVACY`(8항) 시연용 초안. `updateSettings()`는 빈 본문 거부("이용약관 본문은 비울 수 없습니다"), 스냅샷 로드 검증 동일. 구 스냅샷은 기본값 병합으로 하위 호환.
- 관리자 "설정" 탭 **약관·개인정보처리방침** 카드(textarea 2개 + 저장), "기본값 복원"에 포함.
- 랜딩 **푸터**(`.land-footer`): 이용약관 · 개인정보처리방침 버튼 → 본문 인라인 펼침(`.legal-doc`, 로그인 불필요) + © 표기.

## 28-37-03 · 가입 동의 UI + 마이페이지 동의 내역 [반영]

- 고객·파트너 가입 폼 `.consent` 블록: 전체 동의 / [필수] 이용약관 / [필수] 개인정보 수집·이용 / [선택] 마케팅 수신, 필수 2건은 "보기"로 본문 인라인 표시. 전체 동의는 3개 모두 체크일 때만 체크 상태.
- 마이페이지 "동의 내역" 카드: 필수 동의일 2행 + 마케팅 수신 행(수신 중/철회/미동의 + 변경일 + 토글 `aria-label="마케팅 수신 동의"`).
- 실측 중 발견·수정: 최초 구현은 동의 카드가 비밀번호 카드의 메시지 state를 공유해 "철회했습니다" 안내가 두 카드에 중복 표시됨 → 동의 카드 전용 state로 분리 후 재실측.

## 28-37-04 · e2e + 실측 [반영]

- e2e 4단계 추가(51→**55**): 랜딩 푸터 이용약관 열기 / 필수 약관 미동의 → 가입 거부 / 마이페이지 마케팅 수신 중 / 철회 표시. 기존 고객·파트너 가입 단계에 "전체 동의" 체크 삽입. 전 여정 무회귀.
- 실측 4장: 가입 동의 블록(미동의 거부 문구 + 약관 보기), 랜딩 푸터 약관, 마이페이지 동의 내역(철회), 관리자 약관 설정.

## 기타
