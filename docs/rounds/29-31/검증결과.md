## 1. 고치기 전 — 실패 증거

**(1) 고를 목록이 없다.** 새 HTTP 테스트를 고치기 전 코드에 돌렸다:

```
❯ tests/companyPage.http.test.ts (3 tests | 1 failed)
   × 내가 올린 사진 목록이 온다 — 이것이 없으면 커버·로고를 고를 수가 없다
AssertionError: 내 사진 목록이 오지 않는다: expected undefined to be defined
```

나머지 2건(공개본 왕복·남의 사진 거부)은 고치기 전에도 통과한다 — 도메인은 이미 옳았고, **읽는 쪽이 없었을
뿐**이다. 그래서 이 라운드의 진짜 실패 증거는 아래 (2)다.

**(2) 공개본을 읽는 화면이 없다.**

```
$ grep -rn "company/.*page" components/ app/ --include=*.tsx   # 고치기 전
(없음)
```

편집기는 "공개했습니다. 이제 손님이 이 화면을 봅니다." 라고 말하고, 손님 화면은 커버·로고·강조 색·영역
순서·대표 사례 중 어느 것도 그리지 않았다. 이것은 단위 테스트가 못 잡는다(화면 테스트가 수집 대상이 아니다) —
그래서 봇이 걷는다: `e2e:roles` 의 "손님 업체 화면에 그 커버가 보인다" 가 고치기 전에는 없던 단언이다.
