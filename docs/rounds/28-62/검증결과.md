### 고친 실패 5건
1. **기존 시한폭탄**: `입찰 모델 정렬 (28-6-01)`이 `bidDeadline: '2026-09-03'`을 하드코딩해 자정(UTC 2026-09-04)이
   지나며 실패했다. 이번 변경과 무관하며 `addDays(todayUTC(), 3)`으로 고쳤다. (같은 파일의 다른 날짜 테스트는
   `today` 인자를 명시로 넘겨 시각 독립이라 손대지 않았다.)
2. `exportData()`는 호출마다 `savedAt`을 새로 찍으므로 문자열 동일성 비교가 성립하지 않는다 → `savedAt`을 뺀 정규화 비교로.
3. 프로필 저장 API는 `saveProfile`이 아니라 `updateProfile(input, partnerId)`.
4. **자체 검사가 진짜 유출을 잡았다**: 가명본 내보내기가 `PlatformError`로 실패해 e2e 다운로드가 타임아웃됐다.
   원인은 `CompletedJob.payout.account`("국민은행 123********234 (반듯설비)")의 예금주였다. 허용 목록으로 막았다.
5. 가명본 모드 안내 문구를 바꾸면서 e2e 단언(`'고객 A'` 포함)이 어긋났다 → `'가명'`으로.
