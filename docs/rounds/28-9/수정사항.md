## 항목별 수정 내용

### 28-8-01 [중] 진행 단계 시각화 → 수정
- `WorkStepper` 컴포넌트: **낙찰 → 방문 예정 → 시공 중 → 작업 완료 → 정산 완료** 5단계 — 완료 단계 체크(브랜드 연녹), 현재 단계 채움(브랜드), 연결선 색 전이. 미낙찰/취소 카드에는 표시하지 않음.

### 28-8-02 [중] 작업 체크리스트 → 신규 구현
- 도메인: `CHECKLIST_ITEMS`(현장 방문 및 실측 / 자재 수급 / 작업 일정 확정) 고정 3항목, `checklistFor()` / `toggleChecklistItem()` — 존재하는 요청·유효한 키만 허용, 토글 시 자동 저장.
- 스냅샷: `checklists` 선택 필드(하위 호환) + 요소 검증(알 수 없는 키·비불리언 거부).
- UI: 낙찰~시공 중 카드에 체크박스(완료 시 취소선), 마이 탭에 항목 안내.
- 회귀 테스트 5개 (토글·영속·거부·구 스냅샷 호환·오염 거부).

### 28-8-03 [중] 모바일 하단 탭바 → 수정
- ≤640px에서 탭 바를 **하단 고정 내비게이션**으로 전환 (시안 모바일 5탭 구조), 본문 하단 여백 확보. Playwright 390px 뷰포트 스크린샷으로 확인.

### 28-8-04 [하] 파트너 프로필(마이) → 신규 구현
- 도메인: `PartnerProfile`(업체명 필수·공백 정리), `getProfile()` / `updateProfile()`, 스냅샷 `profile` 선택 필드 + 검증.
- UI: '마이' 탭 — 프로필 카드 + 등록/수정 폼.
- 회귀 테스트 4개 (저장·필수값·round-trip·구 스냅샷·오염 거부).
