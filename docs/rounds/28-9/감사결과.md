# 28-9 감사결과 (GPT 역할 — Claude 세션 대리 수행)

감사 범위: `28-9` 전체 + 사용자 피드백("기본 틀부터, UI를 정말 세련된 느낌으로") 반영.
사전 확인: `tsc --noEmit` 0 오류, vitest 124/124, node --test 7/7. 28-8 감사 4건(스텝퍼·체크리스트·모바일 탭바·프로필) 전부 수정 확인됨.

참고: 이 라운드부터 저장소가 **bandut-partner-platform**(파트너 플랫폼 전용, 별도 사업)으로 분리됨 — home-repair-landing(기존 사업)은 원상복구 후 더 이상 접근하지 않는다.

이번 감사는 **시각적 세련미(프리미엄 톤)** 관점의 심화 감사다. 기능은 갖춰졌으나 "만든 티"가 나는 지점들을 항목화한다.

---

## 상 (High — 기본 틀의 세련미)

### 28-9-01 · 타이포그래피 체계 부재
글자 크기가 요소별로 산발적(11~21px)이고 자간·행간 리듬이 없다. 금액·숫자에 tabular-nums가 일부만 적용된다.
→ 요구: 명시적 타입 스케일(캡션 12 / 본문 13.5 / 제목 15 / 헤드 18 / 디스플레이 22+), 제목 자간 -0.02em, 숫자 전역 tabular-nums, 위계별 굵기 규칙(400/600/700/800).

### 28-9-02 · 엘리베이션·서피스 위계가 단조로움
모든 카드가 같은 그림자·같은 라운드라 화면이 평평하다. 호버 반응이 없어 정적인 인상.
→ 요구: 2단 그림자 체계(기본: 미세 / 호버: 부양 + transform), 라운드 14px, 배경-카드-강조 서피스 3단 구분, 카드 진입 시 subtle fade/slide 애니메이션(prefers-reduced-motion 존중).

### 28-9-03 · 아이콘 부재 — 텍스트만으로 구성된 내비게이션·지표
탭과 지표 타일이 순수 텍스트라 스캔이 느리고 밋밋하다 (시안은 아이콘+라벨 구조).
→ 요구: 자체 인라인 SVG 아이콘 세트(홈/검색/작업/캘린더/지갑/사용자 + 지표용 4종, 1.5px 스트로크, currentColor) — 탭바(모바일 포함)와 지표 타일에 적용. 외부 아이콘 라이브러리 금지(번들 유지).

## 중 (Medium)

### 28-9-04 · 헤더가 단색 바에 그침
브랜드 인상을 만드는 첫 요소인데 평면 네이비 단색이다.
→ 요구: 딥 네이비 그라디언트 + 미세한 하이라이트, 로고 마크 정제, 헤더와 콘텐츠 사이 시각적 완충.

### 28-9-05 · 빈 상태(empty state)가 한 줄 텍스트
"일감이 없습니다" 류가 회색 한 줄이라 화면이 죽는다.
→ 요구: 아이콘 + 안내 문구 + 다음 행동 유도(CTA)를 갖춘 빈 상태 컴포넌트로 통일.

### 28-9-06 · 버튼·입력의 마감 부족
버튼에 눌림/포커스 피드백이 약하고, 입력 포커스 링이 투박하다.
→ 요구: 버튼 프레스 스케일·그림자 전이, 세련된 포커스 링(brand 2px + 오프셋), 입력 hover 보더 전이.
