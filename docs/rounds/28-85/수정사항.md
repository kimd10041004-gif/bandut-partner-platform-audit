## 01 (상) `hidden` 판정은 **수식어만** 본다

**원인.** `const hidden = /private|protected/.test(m[0])` — `m[0]`은 `\n  ` + 수식어 + **이름** + `(` 전체다.
이름에 `private`/`protected`가 들어간 **공개** 메서드가 `publicNames`에서 조용히 빠졌다.

**수정.** 수식어를 따로 캡처한다(`(?:…)*`를 그룹으로 묶어 `m[1]`), `/\b(?:private|protected)\b/.test(mods)`.

**수정 전 실패 인용.** 개인정보를 여러 라운드 다룬 이 저장소에서 그럴듯한 이름으로 심었다:

```ts
privateNotesSummary(partnerId: string, options: { excludeSeeded?: boolean } = {}): number
```

```
수정 전 → Tests 5 passed (5)          ← 유도에서 빠지고, PartnerCard가 그것을 불러도 여전히 5 passed
수정 후 → × 금지 목록이 도메인에서 유도한 집합을 모두 담는다
          expected [ 'privateNotesSummary' ] to deeply equal []
```

판정 자체를 고정하는 테스트도 더했다(「숨김 판정은 수식어만 본다」).

## 02 (상) 문자열과 템플릿 리터럴의 구멍 둘

**원인.** `stripNonCode()`가 따옴표 문자열과 **템플릿 전체**를 지웠다. 그래서 두 가지가 통과했다.

**수정.**
- 템플릿은 `${…}` **안을 남기고** 바깥 텍스트만 비운다(중괄호 깊이를 센다).
- 따옴표 문자열은 비우되 **내용을 따로 모아**(`stringLiterals`) 함께 검사한다.
  정당하게 이름을 문자열로 써야 하는 파일은 `guard-ok` 주석으로 면제한다(파일 단위라 아껴 쓴다).

**수정 전 실패 인용.**

```
platform['partnerSummary'](partnerId)
  수정 전 → Tests 5 passed (5)
  수정 후 → + "src/ui/PartnerCard.tsx → partnerSummary (문자열)"

`완료 ${platform.partnerSummary(partnerId).done}건`
  수정 전 → Tests 5 passed (5)
  수정 후 → + "src/ui/PartnerCard.tsx → partnerSummary"
```

템플릿 쪽이 더 중요하다 — JSX에서 `aria-label`·툴팁을 만들 때 **우회 의도 없이** 나오는 모양이다.

## 03 (중) 랜딩 진입점도 라우팅에서 유도한다

**원인.** `customerRoots()` 안에 `if (m[1] === 'Landing')` — 라우팅에서 유도한다는 함수에
**이름 하나가 손으로 적혀** 있었다. 28-84가 28-83에게 한 지적이 한 칸 안쪽으로 옮겨진 것뿐이다.

**수정.** `showLanding` 삼항의 참 가지에서 뽑는다:
`/showLanding\s*\?\s*\(?\s*<([A-Z][\w$]*)/`. 근거(`showLanding = activeApp.key === 'customer' && landing`)는
이미 코드에 있었다.

**수정 전 실패 인용.** 컴포넌트를 `PublicHome`으로 바꿔 보면:

```
라우팅에서 뽑은 랜딩 진입점: Landing
이름을 PublicHome 으로 바꿔도: PublicHome ← 따라온다
28-84 방식(하드코딩 'Landing') 이었다면: (못 찾음) ← 조용히 빠진다
```

## 05 서버 모드 익명 방문자 — **결정하고 닫았다** (네 라운드 이월 종결)

### 무엇이 문제였나

서버 모드에서 `/api/snapshot`은 세션을 요구한다. 로그인하지 않은 랜딩 방문자는 로컬 스냅샷이 비어 있어
`publicStats()`가 항상 0이었고, 따라서 `showPublicStats`가 언제나 false였다 —
**28-79~82가 네 라운드에 걸쳐 세운 "서버 모드에서는 보여준다"가 아무에게도 닿지 않았다.**

### 결정: 만든다. 단, 집계 다섯 개만.

`GET /api/public-stats?workspace=…` — **세션을 요구하지 않는 유일한 읽기 경로**.

**나가는 것**: `PublicStats` 다섯 개(누적 요청·완료 건수·낙찰률·평균 별점·리뷰 수). 전부 집계, 시드 제외.
**나가지 않는 것**: 스냅샷 본문, 요청 내용, 고객·파트너 이름, 지역, 전화번호, 리뷰 본문.
`/api/snapshot`은 세션 게이트 **그대로**다 — 공개 통로를 낸 것이지 문을 연 것이 아니다.

**왜 이만큼이 허용되는가.** 이 다섯 숫자는 서버 모드 랜딩 히어로에 그대로 걸리는 값이다.
랜딩은 정의상 공개 페이지이므로 이 엔드포인트가 **새로 드러내는 것은 없다** —
의도한 화면이 이미 보여주기로 한 것에 통로를 준 것뿐이다.

**알고 감수하는 것 (숨기지 않는다).**
- **거래량이 드러난다.** `totalRequests`는 경쟁자에게 사업 규모를 알려준다. 새 노출이 아니라
  28-79~82가 "랜딩에 내건다"고 정할 때 이미 받아들인 대가다. 되돌리려면 랜딩에서 그 블록을
  내리면 되고(`showPublicStats`), 그러면 이 엔드포인트를 부르는 곳도 함께 없어진다.
- **레이트리밋이 없다.** 60초 캐시로 원본 조회는 줄지만 남용 자체를 막지는 않는다.
  집계 다섯 개라 유출 가치가 낮아 이번 범위 밖으로 두었다 — 엣지 레이트리밋은 계속 이월이다.

**계산을 두 벌로 만들지 않았다.** `PlatformService.publicStatsOf(body)` 하나를 서버가 그대로 부른다.
28-81-03의 교훈(규칙이 두 벌이면 조용히 다른 값을 말한다)을 서버·클라이언트 사이에도 적용했다.

### 테스트를 어디에 두었는지 — 그리고 **무엇이 바뀌었는지**

서버 모드 지표는 이제 **비동기**로 온다. `renderToString`은 이펙트를 돌리지 않으므로,
**SSR로는 "서버 모드에서 지표가 그려진다"를 더 이상 증명할 수 없다.** 정직하게 나눴다:

| 무엇 | 어디서 |
|---|---|
| 받아 오는 경로(성공·4xx·네트워크 끊김·잘못된 JSON) | `usePublicStats.test.ts` — `fetchPublicStats()`를 직접 태운다 |
| 무엇이 나가고 무엇이 안 나가는가 | `api/publicStats.test.ts` — 응답에 이름·지역·요청 내용이 없음을 단언 |
| 첫 페인트에 0을 내걸지 않는다 | `Landing.serverDefault.test.tsx`(의미가 바뀌었다 — 파일 상단에 적었다) |
| 익명으로 실제 응답을 받는다 / 스냅샷은 여전히 401 | `scripts/e2e-server.mjs` — 진짜 브라우저·진짜 엔드포인트 |

**28-84-02 테스트의 의미가 바뀐 것을 조용히 넘기지 않았다.** 그 테스트는 "서버 빌드에서 지표를
그린다"를 단언했는데, 이제 "첫 페인트에 아무것도 그리지 않는다"를 단언한다. 기본값이 `AUTH_MODE`에
묶여 있다는 원래 목적은 유지된다(기본값이 `local`로 새면 로컬 스냅샷을 그려 버려 실패한다).
`Landing.test.tsx`의 서버 모드 케이스도 같은 이유로 새 진실로 바꿨고,
**스킵 테스트를 남기지 않았다** — 옮긴 단언은 지우고 어디로 갔는지 주석으로 적었다.

## 부수 발견 — `api-server.mjs`가 포트 인자를 버리고 있었다

이번 라운드에 엔드포인트를 붙이며 발견했다. 감사 항목이 아니라 **작업 중 마주친 것**이다.

```js
const positional = argv.filter((a, i) => a !== '--static' && i !== staticIdx + 1)
```

`--static`이 없으면 `staticIdx`가 -1이라 `staticIdx + 1`이 **0** — 첫 위치 인자(포트)가 걸러졌다.
`node scripts/api-server.mjs 3102`가 **조용히 3101로** 떴다. 한 줄로 고쳤다(`skip = staticIdx >= 0 ? … : -1`).
