## 6. 아직 확인되지 않은 것

- **진짜 메일 한 통.** 발송사 키가 없어 로컬·CI 는 응답에 코드를 싣는 길로 돈다. `server/mail.ts` 의 요청
  모양은 단언으로 고정했지만 **Resend 가 실제로 받아 보내는 것은 아무도 못 봤다.** 사장님이 키를 넣고
  프리뷰(`AUTH_DEV_OTP` 없이)에서 내 계정 → 이메일 등록을 한 번 하시면 그것이 첫 확인이다.
- **배포된 주소** — 여전히 세션에서 막혀 있다(프록시 403).
- 문자 발송 코드 · 사진 저장소 · 결제사 — 이월.
- **타이밍 오라클(자체 감사 05 잔여).** 복구 요청의 응답은 같지만, 아는 주소일 때만 발송사를 부르므로 응답 시간이
  다르다. 없애려면 발송을 요청 밖(큐)으로 빼야 하고, 그것은 이 라운드가 아니다.
