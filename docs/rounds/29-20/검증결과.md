## 5. 비밀값 준비 (2026-09-11)

사장님이 Vercel Preview 환경의 `ADMIN_PASSWORD`·`SIGNUP_CODE` 를 새 값으로 정하시고, 같은 값을
GitHub 저장소 비밀값(`PREVIEW_ADMIN_PASSWORD`·`PREVIEW_SIGNUP_CODE`)에 넣으셨다.
**값은 이 대화에도 이 문서에도 남지 않는다.**

기존 값이 Vercel 화면에서 `[Hidden]` 으로만 보여 읽을 수 없었다. 읽으려 애쓰는 대신 새로 정해
덮어쓰는 길을 택했다 — 가입 코드는 서버가 매번 환경변수와 직접 대조하므로 그것으로 충분하다.

### 관리자 비밀번호는 이 방법으로 안 될 수 있다

비밀번호는 `auth_state` 행이 **처음 만들어질 때 한 번만** 심어진다(`server/authState.ts:44`).

```ts
if (row === undefined) {
  auth.bootstrapOwnerPassword(adminPassword)
}
```

프리뷰 DB 에 이미 그 행이 있으면 새 `ADMIN_PASSWORD` 는 저장된 비밀번호를 바꾸지 못한다.
로컬에서 봇이 정확히 그것에 걸렸다(29-18 §3-다).

**미리 단정하지 않는다.** 봇을 돌리면 어느 쪽인지 나온다 — 29-18 에서 로그인 실패 시 "저장된
비밀번호가 ADMIN_PASSWORD 와 다를 수 있다"를 함께 싣도록 고쳐 뒀다. 그 답을 보고 다음을 정한다.

## 6. 첫 실행이 내 배선 실수를 잡았다 (29-20-2)

비밀값이 준비된 뒤 처음 돌렸더니 봇이 시작하자마자 죽었다.

```
[e2e:signup] https://...vercel.app (배포된 주소)
[e2e:signup] playwright-core를 찾을 수 없습니다. PLAYWRIGHT_CORE_PATH를 지정하세요.
```

브라우저 설치 단계를 `inputs.browser` 에만 묶어 놨다. `signup` 만 켜고 돌리면 설치가 건너뛰어진다.
봇도 브라우저가 필요한데 그것을 잊었다. `browser || signup` 로 고쳤다.

같은 로그가 **비밀값이 제대로 들어왔다**는 것도 보여 준다 — 건너뛰기 분기로 가지 않았고,
환경에 `ADMIN_PASSWORD: ***` · `SIGNUP_CODE: ***` 가 가려진 채로 찍혔다.

그리고 배포 확인은 이번에도 `ENV_READY: yes` · `ENV_DB: ok` 였다.

## 7. 두 번째 실행 — 세 줄 통과, 가입에서 멈췄다 (29-20-3)

브라우저를 받은 뒤 봇이 배포된 프리뷰에서 실제로 돌았다.

```
✓ 공개 로그인 화면에 관리자 선택지가 없다
✓ 가입 코드가 틀리면 거절한다
✓ 필수 동의 없이는 가입할 수 없다
실행 중 오류: page.waitForSelector: Timeout 15000ms exceeded
  - waiting for locator('[data-otp-input]')
```

앞의 셋은 **배포된 서버가 옳게 거절한다**는 확인이다. 틀린 가입 코드와 동의 없는 가입을
실제 배포가 막았다.

넷째에서 멈췄다. 제대로 채운 가입이 인증번호 화면으로 넘어가지 않았다.

**실패가 이유를 말하지 않는다 — 그게 문제다.** 가입이 거절되면 화면에 오류 문구가 뜨는데,
봇이 인증번호 칸만 기다려서 "Timeout" 으로만 남았다. 무엇이 틀렸는지 아무도 모르는 실패다.
29-18 에서 관리자 로그인 쪽을 같은 이유로 고쳤는데 여기는 빠뜨렸다.

인증번호 칸과 오류 문구 중 **먼저 오는 것**을 받도록 고쳤다. 다음 실행은 원인을 이름으로 말한다.
