# 28-48 수정사항 (Claude) — 운영 리포트 라운드

기반: `28-47` 복사본(스크래치 wf28-48)에서 작업. 28-47 감사 4건 전부 반영.

## 28-47-01 · 원장 도메인 + CSV [반영]

- `LedgerRow { date, type(예약금|최종결제|환불|파트너지급|플랫폼수수료), requestId, counterparty, amount(+입금/−출금), ref, memo }`. `ledger(month?)`: 결제 전부, 환불은 **완료 건만**(음수), 파트너 지급(음수, 계좌 표기 참조), 플랫폼 수수료는 **정산 확정 작업**(완료일 기준) — 날짜·요청·구분순. `ledgerMonths()`(최신순), `ledgerSummary(month?)`(입금·출금·수수료·순액·행 수), `partnerLedger(partnerId)`(내 완료 작업 총액·수수료·지급액·정산 확정·지급일·계좌).
- `domain/csv.ts`: `csvCell`(쉼표·따옴표·줄바꿈 이스케이프), `toCsv(headers, rows)`(UTF-8 BOM + CRLF). 테스트 파일 신규(`csv.test.ts`) + 원장 테스트 1건 → vitest 203→**205**. (초안 테스트는 `driveToInProgress`가 예약금 없이 진행하는 것을 놓쳐 1회 실패 → 기대값 정정.)

## 28-47-02 · 관리자 정산 감독 내보내기 [반영]

- 정산 감독 최상단 **월별 원장** 카드: 월 select(`aria-label="원장 월"`), 요약(`data-ledger-summary`), 건별 표(`.ledger-row`, 출금은 `−` 표기), **CSV 내보내기**(`data-export-ledger`, `ledger-YYYY-MM.csv`). `ui/download.ts` `downloadText`를 신설해 대시보드 백업(JSON)도 공유.

## 28-47-03 · 파트너 정산 내역 내보내기 [반영]

- 파트너 정산 탭 "내 정산 내역 CSV"(`data-export-settlement`, `settlement-<partnerId>.csv`) — 파트너 범위.

## 28-47-04 · e2e + 실측 [반영]

- e2e 3단계 추가(101→**104**): 원장 행·요약 표시 / 관리자 CSV 다운로드 이벤트 → BOM·한글 헤더·행 수 = 화면 행 수·파일명 / 파트너 CSV 헤더·지급 완료(`Y`)·파일명. 실측 1장 + CSV 첫 줄.
