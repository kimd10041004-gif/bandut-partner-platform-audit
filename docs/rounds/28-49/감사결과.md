# 28-49 감사결과 (GPT 역할 — Claude 세션 대리 수행)

감사 범위: `28-49` 전체 — 요청 사진 반영 후, **저장 용량과 사진의 생애주기** 점검.
사전 확인: `npm run check` exit 0 (vitest 206/206), e2e 107/107 PASS, visual-check 전 항목 PASS, `npm audit` 0건, 프로덕션 배포 그린(PR #126 머지). 28-48 감사 4건 전부 수정 확인됨.

핵심 지적: 28-49로 요청 하나가 최대 600KB를 차지하게 됐는데, `PlatformService.save()`는 **저장 실패를 조용히 삼킨다**(`catch {}`). localStorage(약 5MB)가 차면 고객이 "요청을 등록했습니다"를 보고도 새로고침하면 사라지는 **무언의 유실**이 생긴다. 또 사진을 지우는 규칙이 없어 정산·취소된 거래의 사진이 영원히 남는다(개인정보·용량 모두 문제). 마지막으로 파트너가 시공 결과를 증빙할 사진이 없어 최종 결제·A/S 분쟁 시 근거가 없다.

---

## 상 (High)

### 28-49-01 · 저장 실패 가시화 + 용량 관측
→ 요구: `save()`가 실패를 기록·통지한다 — `lastSaveError: string | null`, `onSaveError?(message)` 콜백(옵션·속성), 반환값 boolean. `storageUsage()` → `{ chars, photoChars, photoCount, limit, ratio }`(직렬화 스냅샷 문자 수 기준, localStorage는 UTF-16 문자 단위이므로 문자 수가 기준). `STORAGE_SOFT_LIMIT = 4MB`(`PlatformOptions.storageLimit`로 주입 가능). 사진을 늘리는 쓰기(`addRequest`·`addPhoto`·완료 사진)는 **변경 전에** 예상 용량이 한도를 넘으면 `PlatformError('저장 공간이 부족합니다 …')`로 거부한다. 앱 셸에 저장 실패 배너(`role="alert"`, `[data-save-error]`)를 띄우고 다음 저장 성공 시 지운다. **도메인 테스트 필수**(실패 저장소 주입·한도 주입).

### 28-49-02 · 사진 보관 정책
→ 요구: `PHOTO_RETENTION_DAYS = 90`. `prunePhotos(today, retentionDays?)`: 정산 완료(`settled`, 완료일 기준)·취소(`cancelled`, 환불 생성일 또는 요청 생성일 기준) 거래가 보관 기간을 지나면 현장 사진·완료 사진을 제거하고 제거한 요청 수를 반환(멱등). 관리자 현황 진입 시 다른 sweep과 함께 실행. 관리자 현황에 **저장 용량 카드**(`[data-storage]`): 사용량/한도 막대, 사진 장수·용량, "오래된 사진 정리" 버튼. 테스트: 100일 경과 제거·30일 유지·재실행 0.

## 중 (Medium)

### 28-49-03 · 시공 완료 사진
→ 요구: `RepairRequest.completionPhotos?: RequestPhoto[]`(같은 `validatePhotos` 규칙, 최대 3장). `setCompletionPhotos(requestId, partnerId, photos)`: 낙찰 파트너만, `in_progress`/`completed` 상태에서 **최종 결제 전까지**. 파트너 내 작업 카드에 "완료 사진" 파일 입력(`aria-label="완료 사진"`, 리사이즈 재사용) + 썸네일·삭제. 고객 거래 상세의 최종 결제 카드 위에 "시공 완료 사진", 관리자 거래 상세에도 표시(`[data-completion]`). 스냅샷 검증 포함.

### 28-49-04 · e2e + 실측
→ 요구: e2e — 시공 중 완료 사진 1장 첨부 → 파트너 카드 `[data-completion] .photo-thumb` 1 → 고객 거래 상세 완료 사진 1 → 관리자 저장 용량 카드에 사진 장수 표시 → localStorage를 채워 저장 실패를 유발한 뒤 배너 표시·정리 후 배너 해제. 도메인 상한·정리 규칙은 vitest. 실측: 저장 용량 카드·완료 사진 첨부 화면.
