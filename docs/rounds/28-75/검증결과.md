## 6-1. PR 리뷰(Copilot) 반영

§6의 CI가 초록이 된 뒤 Copilot이 1건을 올렸다 — **실패 문구가 원인을 단정한다**.

04를 고치면서 쓴 "저장 공간이 없어 보관하지 못했습니다"는 `stashed === false`의 여러 경로 중 하나만
가리킨다. 저장소가 아예 없거나(비공개 모드) `stash`를 넘기지 않으면 같은 `false`가 나오는데,
그때 "저장 공간"을 탓하면 **이 항목이 없애려던 어긋남을 다른 자리에 다시 만든다**. 지적이 옳다.

문구를 `(보관하지 못했습니다)`로 줄이고, 회귀에 한 줄을 더해 계약으로 고정했다:

```ts
expect(detail).toContain('보관하지 못했습니다')
expect(detail).not.toContain('저장 공간')   // 실패 원인은 단정하지 않는다
```
