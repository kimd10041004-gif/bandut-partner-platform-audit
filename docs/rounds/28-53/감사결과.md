# 28-53 감사결과 (GPT 역할 — Claude 세션 대리 수행)

감사 범위: `28-53` 전체 — 낙찰 전 수정 반영 후, **거래 종료 이후(A/S·리뷰)의 파트너 응답 경로** 점검.
사전 확인: `npm run check` exit 0 (vitest 220/220), e2e 124/124 PASS, visual-check 전 항목 PASS, `npm audit` 0건, 프로덕션 배포 그린(PR #142 머지). 28-52 감사 4건 전부 수정 확인됨.

핵심 지적: 정산이 끝난 뒤의 규칙이 비어 있다. (1) **보증 기간이 없다** — `fileClaim('as')`는 완료·정산 상태이기만 하면 1년 뒤에도 접수되고, 파트너는 무기한 무상 A/S 의무를 진다(집수리 표준은 시공 후 30~90일). (2) A/S·분쟁이 접수되면 알림만 가고 **파트너가 답할 자리가 없다** — 처리는 관리자만 하고, 고객은 파트너가 봤는지도 모른다. 관리자 조치 필요 카드도 "미해결"만 세지 "파트너 무응답"을 구분하지 못한다. (3) 리뷰에 **파트너 답글이 없다** — 낮은 별점에 사정을 설명할 방법이 없어 업체 카드가 일방적이다. 시안 3 업체 상세는 답글을 전제한다.

## 상 (High)

### 28-53-01 · 보증 기간
→ 요구: `SiteSettings.warrantyDays`(기본 90, 정수 0~365, 관리자 설정 탭에서 수정, 스냅샷 검증). `warrantyStatus(requestId, today)` → 완료·정산 건에 `{ until, daysLeft, active }`(완료일 + 보증일), 그 외 `undefined`. `fileClaim('as')`는 보증 만료 후 거부("보증 기간이 지났습니다 (만료 …) — 유상 A/S는 채팅으로 협의"). 분쟁은 영향 없음. 고객 거래 상세에 보증 배지(`[data-warranty]`, D-n/만료), 만료 시 A/S 버튼 대신 안내. **도메인 테스트 필수**.

### 28-53-02 · A/S·분쟁 파트너 답변 + 무응답 운영 큐
→ 요구: `Claim.partnerReply?`·`repliedDate?`. `replyClaim(claimId, partnerId, text, date)`: 낙찰 파트너만, 미해결 건만, 빈 답변 거부, 덮어쓰기 허용(최신 답변), 고객·관리자 알림. `opsQueue.unansweredClaims`(미해결·답변 없음·접수 2일 이상 경과, `CLAIM_REPLY_SLA_DAYS = 2`) + 현황 카드 그룹 `data-ops="unanswered"`. 파트너 내 작업 카드에 접수 상세 + 답변 입력(`aria-label="A/S 답변"`), 고객 거래 상세·관리자 A/S 탭에 답변 표시(`[data-claim-reply]`).

## 중 (Medium)

### 28-53-03 · 리뷰 답글
→ 요구: `Review.reply?`·`repliedDate?`. `replyReview(requestId, partnerId, text, date)`: 그 요청의 파트너만, 빈 답글 거부, 수정 가능, 고객 알림. 파트너 마이 탭 리뷰 목록에 답글 입력(`aria-label="리뷰 답글"`), 고객 업체 카드·관리자 리뷰 탭에 답글 표시(`[data-review-reply]`).

### 28-53-04 · e2e + 실측
→ 요구: e2e — A/S 접수 후 파트너 답변 → 고객 거래 상세에 답변 표시 → 관리자 A/S 탭 답변 표시 / 리뷰 답글 → 업체 카드 답글 / 관리자 설정 보증일 변경 → 저장. 보증 만료 거부·무응답 큐는 vitest. 실측: 보증 배지·A/S 답변 폼·리뷰 답글·설정.
