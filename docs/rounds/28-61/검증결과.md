### 고친 실패 6건 (원인을 모두 끝까지 봤다)
1. vitest `가명본…` — `expect(json).not.toContain('곰팡이')` 실패. **유출이 아니라 단언이 넓었다**: '곰팡이'는 기본 질문 시드(`Q-0001 누수나 곰팡이가 있나요?`)에도 있는 단어다. 요청 본문 고유 문구(`새까맣습니다`)로 좁혔다.
2. 같은 테스트 `snap.bids` — 견적은 스냅샷에서 `estimates`로 직렬화된다. 필드명을 바로잡았다.
3. vitest `행위자…` — `toMatchObject({ count: undefined })`가 키 부재를 통과시키지 않아 `toBeUndefined()`로 분리했다.
4. **진짜 유출 1건**: 가명본에 요청 내용이 남았다. 알림 문구가 `reqLabel`(`[분야] 요청 내용`)을 담기 때문이다. `notifications[].text`를 `[가명 처리]`로 지워 막았다 — 테스트가 없었으면 못 잡았을 경로다.
5. e2e 다운로드 3건 — 한글 파일명(`내데이터-`, `banded-backup-가명-`)이 브라우저에서 그대로 오지 않는다. 파일명을 ASCII로 통일했다.
6. e2e `운영 기록 CSV 헤더` — `행위자` 열을 `주체` 뒤에 넣어 기존 접두사 단언이 깨졌다. 새 헤더에 맞춰 갱신했다(`시각,주체,행위자,행위,대상,상세,첫 시각,횟수`).
