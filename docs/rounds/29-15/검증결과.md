# 29-15 검증 결과

## 1. 통합 검사가 보는 것 — 이 라운드의 핵심

```
✓ 처음 여는 편집본은 리비전 0 이고 공개된 적이 없다
✓ 저장하면 리비전이 1 이 된다
✓ 저장만으로는 공개본이 생기지 않는다 (published=false)
✓ 낡은 리비전으로 저장하면 409 — 앞선 변경을 덮지 않는다
✓ 공개하면 손님이 보는 값이 바뀐다
✓ 남의 사례를 걸고 공개하면 403
✓ 그리고 **기존 공개본이 그대로 남는다** — 소개 문구도, 대표 사례 0개도
```

마지막 두 줄이 명세 6절의 "실패하면 기존 공개본은 유지한다"다. 403만 보고 끝냈으면 공개본이
반쯤 바뀌었는지 알 수 없다. 실패 뒤에 공개본을 다시 읽어 확인한다.
