## 4. 이 컨테이너에서 확인하지 못한 것 / 알고도 남긴 것

- 라이브 도메인은 이그레스 정책이 막고 있어 **직접 열 수 없다**. 배포 반영은 병합 뒤 `deploy-check`로 §5.
- **rev 캐시의 실제 DB 경로**는 단위 테스트에서 가짜 풀로 봤다. 진짜 Postgres에서 두 번째 요청이
  본문 조회를 건너뛰는지는 쿼리 로그를 봐야 하는데, `e2e:server`는 그것을 세지 않는다.
  **계약(쿼리 순서)을 고정했다고 적지, 실측했다고 말하지 않는다.**
- **가드가 못 잡는 것**: 이름을 런타임에 만들어 부르는 접근(`platform[key]`, `key`는 변수).
  타입도 흐려져 컴파일러가 모른다. `UI_가이드.md`에 그대로 적었다 —
  28-85 감사 04가 "적어 둔 한계가 실제보다 좁았다"를 지적했으므로, 이번에는 맞는지 확인했다.
- **엣지 레이트리밋 없음.** 02가 요청당 비용을 낮췄을 뿐 요청 수를 막지 않는다. 이월.
- **프로덕션은 여전히 로컬 모드.** 28-68 이후 열아홉 라운드의 서버 작업이 아직 아무에게도 닿지 않는다.
  결함이 아니라 상태이고, 다음 라운드의 결정 후보다.
