# 28-6 수정사항 — 28-5 감사결과 5개 항목 전부 처리

작업 방식: 기존 규칙 그대로 — 28-1~28-5는 일절 수정하지 않고 스크래치 복사본(`scratchpad/wf28-6`)에서 수정 후 `28-6` 스냅샷 생성.

## 항목별 수정 내용

### 28-5-01 [중] 완료 시공 슬롯이 일정에 구분 없이 표시 → 수정
- `upcomingSlots()`가 활성(scheduled/in_progress) 요청의 슬롯만 반환 — 완료·정산·취소된 방문은 '다가오는 일정'에서 제외.
- 대시보드 '오늘 방문 일정'에는 요청 상태 배지를 표시해 끝난 방문을 구분.
- 회귀 테스트: 완료 시 제외 / scheduled·in_progress 포함 — 2개. (감사 시 재현 테스트로 버그 동작을 먼저 확인함.)

### 28-5-02 [중] 백업 요소 수준 검증 부재 (NaN 정산) → 수정
- `parseSnapshot`에 요소 수준 검증(`validateSnapshotElements`) 추가:
  - 요청: id/텍스트 필드 타입, 허용된 상태값, 실제 달력 desiredDate
  - 견적: `validateEstimate` 통과 (정수·음수·할인 초과 검사)
  - 작업: 정수 금액(음수 거부), 실제 달력 completedDate, boolean settled
  - 슬롯: `validateSlot` 통과 (날짜·시간 범위)
- 실패 시 어느 요소가 왜 실패했는지 담은 `PlatformError` + **기존 데이터 보존**.
- 견적 `breakdown`은 저장값을 신뢰하지 않고 `calcEstimate`로 **재계산** (조작된 백업 무력화).
- 회귀 테스트: total 문자열/실수, 불량 상태값, 달력에 없는 날짜, 역전된 슬롯 시간, 실패 시 보존, breakdown 재계산 — 5개.

### 28-5-03 [중] 매출 리포트 부재 → 수정
- `monthlyReport()`: 월(YYYY-MM)별 건수/총액/수수료/지급액 + 정산 확정/미정산 분리, 최신 월부터 정렬.
- 정산 탭 상단에 월별 요약 표 추가.
- 회귀 테스트: 두 달 집계·정산 분리·정렬, 빈 리포트 — 2개.

### 28-5-04 [하] 견적 memo 미노출 → 수정
- 견적 폼에 메모 입력(공백은 저장 안 함), 요청 카드에 메모 표시. 백업 round-trip 유지 테스트 1개.

### 28-5-05 [스코프] 단일 파트너 확정
- 이 앱은 **파트너 1인용 도구**로 확정 — README에 명시. 도메인의 partnerId 분리는 유지(백업 이관·향후 관리자 앱 대비). 다중 파트너 관리(계정/권한)는 별도 관리자 앱 범위로 정의.
