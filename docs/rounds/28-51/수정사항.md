# 28-51 수정사항 (Claude) — 파트너 철회·재오픈 라운드

기반: `28-50` 복사본(스크래치 wf28-51)에서 작업. 28-50 감사 4건 전부 반영.

## 28-50-01 · 파트너 낙찰 철회 + 재오픈 도메인 [반영]

- `PartnerCancel { id, requestId, partnerId, reason, date }`(스냅샷 `partnerCancels`/`partnerCancelSeq`, 복원 시 필드·날짜 검증). `store.clearAcceptedPartner`, `store.reopen(id, 'requested'|'estimated')`(전이표 밖 관리 전이 — accepted/scheduled에서만).
- `withdrawAward(requestId, partnerId, reason, today)`: 낙찰 파트너만, `accepted`/`scheduled`에서만(시공 시작 후 거부), 사유 필수, 날짜 검증. 효과 — 그 파트너 입찰 제거·슬롯 해제·체크리스트 초기화·낙찰 해제 → 다른 입찰이 남으면 `estimated`(다른 입찰자는 `lost`에서 풀림) 아니면 `requested`, 마감 `defaultBidDeadline(희망일, 오늘)`로 재설정(알림 플래그 초기화), 예약금이 있으면 전액 환불 대기(사유 "파트너 철회 — 전액 환불 (…)"), 고객·관리자·다른 입찰자 알림.
- `paymentFor`는 환불(대기·완료)이 걸린 결제를 제외한 최신 건 → 재낙찰 후 예약금 재결제 허용, 최종 결제 차감도 새 예약금 기준. `refundFor`는 최신 환불. `partnerCancels(partnerId?)`(최신순), `partnerCancelCount(partnerId, 90, today)`.
- vitest 2건(210→**212**): 권한·상태·사유·날짜 검증, 재오픈·마감·슬롯·환불·유효 결제·알림·재입찰·재낙찰·재결제·시공 후 거부·스냅샷 왕복·손상 거부 / 다른 입찰 잔존 시 `estimated`·미낙찰 해제·재오픈 알림. 기존 취소·원장 테스트 2건은 환불된 예약금을 `paymentsFor`로 조회하도록 정정.

## 28-50-02 · 신뢰 지표 + 운영 큐 [반영]

- `partnerSummary(partnerId, today)`에 `cancelCount`(최근 90일). 고객 `PartnerCard` "낙찰 후 취소 n회 (90일)" 빨간 태그(`[data-cancel-count]`, 0이면 없음). 관리자 회원 탭 파트너 행 "낙찰 철회 n회 (90일)"(`[data-member-cancels]`).
- `opsQueue.frequentCancellers`(`PARTNER_CANCEL_WINDOW_DAYS = 90`, `FREQUENT_CANCEL_THRESHOLD = 2`) + `counts.frequentCancellers`. 현황 조치 필요 카드 `data-ops="cancels"`(업체명·id·횟수·최근 일자, 회원 탭 정지 검토 안내).

## 28-50-03 · 파트너·고객 화면 [반영]

- 파트너 내 작업 카드(낙찰·방문 예정) `WithdrawAward`: "낙찰 철회" 위험 버튼 → 안내 + 사유 입력(`aria-label="철회 사유"`) + "철회 확정"/"돌아가기". 사유 없으면 도메인 오류 표시. **파트너 쪽 "→ 취소" 버튼 제거** — 파트너 귀책 이탈은 철회(사유·기록·재오픈)로만.
- 고객 거래 상세: 재오픈 배너(`[data-reopen-banner]`), 환불 카드는 견적이 없어도 표시되도록 `PaymentCards` 조건을 `bid || refund`로 확장(초안은 철회 후 견적이 사라지며 환불 카드도 숨어 실측에서 발견 → 정정).

## 28-50-04 · e2e + 실측 [반영]

- e2e 4단계 추가(112→**116**): 파트너 철회(사유) → 내 작업에서 제거 / 일감 탭 재노출(입찰 0건) / 고객 거래 상세 재오픈 배너 / 재입찰 후 견적함 업체 카드 "낙찰 후 취소 1회". (초안은 삽입 앵커가 고객 알림 절의 같은 문장에 먼저 걸려 파트너 탭을 못 찾음 → 매칭 절 뒤로 이동; 업체 카드는 "업체 정보 보기"를 눌러야 렌더.)
- 실측 `capture-28-51.mjs`: 철회 확정 화면, 재오픈 배너 + 환불 대기 카드, 사유 없이 확정 거부, 2회 철회 후 관리자 조치 필요·회원 탭·업체 카드 경고, 남은 슬롯은 시드 건뿐, 모바일 가로 스크롤 없음.
