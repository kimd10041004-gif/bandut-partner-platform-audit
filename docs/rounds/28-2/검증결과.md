## 28-1 무변경 해시 검증

28-2 생성 *전* 28-1 전체 파일(24개, node_modules/dist 제외)의 md5 목록을 baseline으로 저장하고, 28-2 생성 *후* 동일 명령(같은 find 필터, 같은 sort)으로 재생성하여 diff 비교:

```
diff hash-baseline-28-1.txt hash-after-28-1.txt
HASH-IDENTICAL: 28-1 무변경 확인
```

(diff 출력 없음 = 24개 파일 전부 해시 동일)
