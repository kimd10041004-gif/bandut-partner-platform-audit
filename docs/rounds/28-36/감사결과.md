## 상 (High)

### 28-36-01 · 파트너 유형 + 사업자 조회 도메인
→ 요구: `Account.partnerType?: 'business' | 'individual'`(파트너 필수), `bizVerified?: boolean`.
- `isValidBusinessNumber(bizNo)`: 국세청 체크섬(가중치 1·3·7·1·3·7·1·3·5 + 9번째 자리×5의 십의 자리, 검증 자리 = (10 − 합%10)%10). 순수 함수, **단위 테스트 필수**(유효/무효/자릿수).
- `register()`: 파트너는 유형 필수. **사업자**는 사업자번호 필수 + 조회 통과(`verifyBusiness()` 경계 — 현재 체크섬, 상용 시 API) 아니면 "사업자 정보 조회에 실패했습니다" 거부 후 `bizVerified: true`. **개인**은 사업자번호 없이 가입(OTP 본인인증만). 고객 유형 무관.
- 스냅샷 검증(유형 집합) + 왕복.
