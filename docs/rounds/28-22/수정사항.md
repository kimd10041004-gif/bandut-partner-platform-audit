## 항목별 수정 내용

### 28-21-01 [상] SiteSettings 도메인 → 신규 구현
- `SiteSettings { heroTitle, heroSub, notice, disabledCategories, faqs }` + `DEFAULT_SETTINGS`(기본 문구·기본 FAQ 2건).
- `getSettings()`(기본값 병합·복사 반환) / `updateSettings()`(부분 갱신: 히어로 공백 불가, 전 카테고리 비활성 불가, 미지 카테고리·빈 FAQ 질문 거부) / `enabledCategories()`(시안 순서 유지).
- 카테고리 런타임 목록을 도메인 `ALL_CATEGORIES`로 이동(UI constants는 재사용).
- 스냅샷 `settings?` 하위 호환(없으면 기본값) + 요소 검증. 회귀 테스트 3개 → vitest 145→148.

### 28-21-02 [상] 관리자 설정 탭 → 신규 구현 (`AdminSettings`, 시안 3)
- 관리자 콘솔 5번째 탭 "설정": ①카테고리 노출 토글 스위치 13종 ②홈페이지 문구(히어로 타이틀·서브, 줄바꿈 지원) ③공지 배너 ④FAQ 추가/삭제 ⑤기본값 복원. 저장 즉시 반영(임시저장/발행 이원화는 단일 관리자 데모 범위에서 즉시 발행으로 단순화).

### 28-21-03 [상] 고객 웹 설정 반영 → 수정
- 랜딩: 공지 배너(`notice` 있을 때만)·히어로 문구(설정, \n 줄바꿈)·FAQ 아코디언 섹션·카테고리 그리드(`enabledCategories`).
- 위저드: 활성 카테고리만 표시, 사전 선택이 비활성이면 첫 활성 카테고리로 폴백.

### 28-21-04 [중] e2e 운영 시나리오 → 추가
- "관리자가 문구 저장 + 도배 비활성 → 고객 랜딩에 새 문구·카테고리 숨김·FAQ 노출" 4단계 — e2e 16→20단계.

### 28-21-05 [중] 유지보수 경계 문서화 → 수정
