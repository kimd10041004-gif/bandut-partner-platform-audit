## 상 (High)

### 28-22-01 · A/S·분쟁 도메인 부재 (시안 4·5)
→ 요구: `Claim { id, requestId, kind('as'|'dispute'), detail, status('open'→'in_review'→'resolved'), createdDate, resolvedDate?, resolution? }`.
- `fileClaim()`: **A/S는 completed/settled에서만**, **분쟁은 accepted~settled에서만**(견적 전 단계·이탈 건 거부), detail 공백 불가.
- `reviewClaim()`(open→in_review) / `resolveClaim(resolution)`(open·in_review→resolved, 처리 내용 필수) — 관리자 액션.
- `claimsFor()`/`allClaims()`(미해결 우선·최신순)/`openClaimCount()`. 스냅샷 `claims?`+`claimSeq?` 하위 호환 + 요소 검증 + **도메인 테스트 필수**.

### 28-22-02 · 고객 접수 UI 부재 (시안 5 "A/S 요청")
→ 요구: 고객 거래 상세 — 완료·정산 거래에 "A/S 요청" 카드(사유 입력→접수), 진행 중(낙찰 이후) 거래에 "문제 신고"(분쟁) 진입. 접수 내역과 처리 상태(접수됨/검토 중/해결됨 + 처리 내용) 표시.

### 28-22-03 · 관리자 처리 콘솔 부재 (시안 4 "분쟁/클레임")
→ 요구: 관리자 "A/S·분쟁" 탭 — 미해결 우선 목록(유형 뱃지·거래·사유·경과), "검토 시작"/"해결 처리"(처리 내용 입력) 액션, 해결 이력. 현황 탭 지표에 **미해결 접수 건수** 추가(시안 4의 "분쟁 접수" 지표).
