## 4. 이 컨테이너에서 확인하지 못한 것 / 알고도 남긴 것

- 라이브 도메인은 이그레스 정책이 막고 있어 **직접 열 수 없다**. 배포 반영은 병합 뒤 `deploy-check`로 §5.
- **사용자 눈에 보이는 변화는 없다.** 이번 라운드는 전부 가드·테스트·문서다 — 화면 동작과 도메인 계산은
  그대로다(`e2e`·`e2e:server`가 그것을 확인한다).
- **가드는 여전히 정적 텍스트 검사다.** 이름을 부르지 않고 원자료에서 같은 숫자를 계산하는 경로는
  원리적으로 못 잡는다. 이번에 그 한계를 파일 상단과 `UI_가이드.md`에 적었지만, **적은 것과 막는 것은 다르다.**
  타입 기반 검사는 범위 밖으로 두었다(`28-84/수정사항.md`「하지 않은 것」).
- **서버 모드 익명 방문자 문제**는 **세 라운드째 이월**이다(28-82 발견 → 28-83 → 28-84).
  이번 02가 서버 모드 쪽 절반을 **테스트로는** 닫았지만 **화면으로는 여전히 열려 있다** —
  로그인하지 않은 랜딩 방문자는 `/api/snapshot`이 세션을 요구해 아직 지표를 받지 못한다.
