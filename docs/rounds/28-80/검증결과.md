**번들 해시가 일치한다.** §1의 `visual-check`가 확인한 로컬 프로덕션 빌드(로컬 모드)가
`/assets/index-nl6hgRJX.js`였고, 라이브가 서빙하는 번들이 **같은 이름**이다 — Vite의 에셋 해시는
내용에서 나오므로 이름이 같다는 것은 내용이 같다는 뜻이다. 즉 이 문서의 §1·§4에서 검증한 그 빌드가
그대로 라이브에 올라가 있다.

(28-79에서는 이 주장을 하지 않았다. 그때는 마지막 로컬 빌드가 서버 모드 빌드라 해시가 달랐고,
같은지 알 수 없는 것을 같다고 쓰지 않았다. 이번에는 실제로 일치해서 적는다.)

§5에 적은 제약은 그대로다 — 라이브 화면을 **이 컨테이너에서 직접 열어 본 것은 아니다**.
확인한 것은 "로컬에서 검증한 번들이 라이브에 올라가 있다"까지이고, 화면 동작의 근거는
그 번들에 대고 돌린 `npm run e2e`·`npm run visual-check`다.
