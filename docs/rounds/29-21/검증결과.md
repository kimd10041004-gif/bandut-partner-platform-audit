## 4. 봇이 가입 코드 없이 한 바퀴를 돌았다

```
✓ 가입 화면에 가입 코드 칸이 없다
✓ 필수 동의 없이는 가입할 수 없다
✓ 가입 신청이 인증번호 화면으로 넘어간다
✓ 인증번호가 틀리면 거절한다
✓ 가입이 끝나면 파트너 정보 화면으로 간다
✓ 승인 전에는 업체 찾기에 안 보인다
✓ 승인 전에는 일감 화면이 막혀 있다
✓ 관리자로 로그인된다
✓ 승인 뒤 일감 화면이 열린다
✓ 승인 뒤 업체 찾기에 보인다
```

가운데 두 줄이 이 라운드의 논거다. **가입 코드가 없어도 승인 전에는 아무것도 못 한다.**
자물쇠는 운영자 승인 하나로 충분하고, 그것이 실제로 잠겨 있다.

## 5. 내가 낸 실패 하나 — 게이트가 아니라 내 실행이 틀렸다

`e2e:server`를 돌렸더니 DB 를 보는 단언이 줄줄이 빨갛게 나왔다.

```
✗ A: 파트너 가입·OTP·로그인이 /api/auth를 거친다
✗ A: 계정은 서버 행(auth_state)에 있고 해시는 s256$ 형식이다
TypeError: Cannot read properties of undefined (reading 'rev')
```

화면 단계는 통과하는데 DB 단계만 실패해서, 내가 무엇을 깼다고 보기 어려웠다. 그래서
**바꾸기 전 코드로 같은 것을 돌렸다.** 거기서도 같은 자리가 빨갰다.

```
✗ 서버 모드 빌드 표기 (data-auth-mode=server, 29-20)
✗ A: 가입 코드 없이는 가입할 수 없다 (28-70-01)
```

첫 줄이 답이었다. `npm run build` 는 **로컬 모드** 번들을 만든다. 로컬 모드의 SPA 는
`/api/auth` 를 부르지 않으니 DB 에 아무것도 안 남는다. CI 는 그 앞에
`VITE_AUTH_MODE=server npx vite build` 를 돌린다 — 내가 그 줄을 빠뜨렸다.

같은 명령을 넣고 다시 돌리니 55개 전부 통과했다. **내 회귀가 아니라 내 실행이 틀린 것이었고,
단정하기 전에 바꾸기 전 코드로 재보는 것이 그것을 갈랐다.**
