# 29-14 검증 결과

## 1. 검사가 설계 하나를 되돌렸다

질문·답변마다 알림을 넣으려 했는데 통합 검사가 곧바로 막았다.

```
AssertionError: {"error":"다른 변경 사항이나 일정 충돌이 있습니다. 새로고침 후 확인해 주세요."}:
  expected 409 to be 201
```

`notifications.order_id`가 NOT NULL이었다. 그 표는 주문에 매인 알림용이다. 질문 하나 때문에
v17 표를 바꾸지 않기로 하고 알림을 뺐다 — 받은 질문함의 미답변 우선 정렬이 그 자리를 대신한다.
코드에 이유를 적어 뒀다.

## 2. 권한 경계를 실제로 확인했다

```
✓ 고객이 질문을 남긴다 (201)
✓ 로그인 없이 목록이 읽힌다 (200)
✓ 질문자 이름이 "김OO" 로 나가고 원래 이름이 응답에 없다
✓ 남의 업체가 답하려 하면 403 — 이 줄이 이 검사의 이유다
✓ 그 업체가 답하면 200 이고 공개 목록에 답변이 붙는다
✓ 관리자가 숨기면 공개 목록에서 사라진다
✓ 숨겨도 업체의 받은 질문함에는 남는다 — 답변 대상이다
```
