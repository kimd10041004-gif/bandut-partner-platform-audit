## 상 (High)

### 28-32-01 · 요청-계정 연결 부재
→ 요구: `RepairRequest.customerId?`(계정 ID) — 위저드 제출 시 로그인 세션의 accountId 탑재. 고객 앱(홈 지표·거래 목록·견적함)은 **내 요청만** 표시(customerId 일치). 계정 연결이 없는 구 데이터·시드 요청은 고객 앱에서 숨김(파트너 일감·관리자 전체 조회는 그대로 — 역할별 조회 범위가 다른 것이 정상). 스냅샷 요소 검증 + **도메인 테스트 필수**.

### 28-32-02 · 위저드 이름 중복 입력
→ 요구: 작업 올리기 1단계에서 이름 입력 제거 — 로그인한 고객 이름을 자동 사용(등록 확인 단계에는 표기). 검증 문구도 정리.
