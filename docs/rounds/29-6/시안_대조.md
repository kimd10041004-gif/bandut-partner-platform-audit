`/privacy` 만 다섯 줄 다른데, 그것은 이번에 **일부러** 바꾼 문구다.

## 2. `/privacy` 의 다섯 줄 — 의도한 차이

시안은 ChatGPT 로그인을 전제로 쓰여 있다. 우리는 로그인을 우리 것으로 바꿨으니 문구도 따라
바뀌어야 한다.

| | 시안 | 우리 |
|---|---|---|
| 수집 항목 첫 줄 | "**ChatGPT 로그인 식별자와 이메일·표시 이름**, 접수 연락처, …" | "**가입 시 입력한 이름과 휴대폰 번호**, 접수 연락처, …" |
| 서비스 제공 기반 | "이 검토용 사이트는 **ChatGPT 로그인과 Sites 저장 기반**을 사용합니다." | "**회원 인증과 데이터 저장은 이 플랫폼이 직접 운영합니다.**" |

## 3. 그림은 실제로 다르다 — 사장님이 고를 자리

시안이 부르는 이미지 파일이 우리 저장소에 없다. 29-6 이 우리 파일 이름으로 바꿔 달아
404 를 없앴는데, **이름만 바꾼 것이 아니라 사진 자체가 다른 것으로 바뀌었다.**

| 화면 | 시안이 쓰는 파일 | 우리가 쓰는 파일 |
|---|---|---|
| 로고 (모든 화면) | `/brand/logo.png` | `/brand/logo-mark.png` |
| 홈·서비스 메인 | `/home-interior.webp` | `/brand/hero-main.jpg` |
| 요청 화면 | `/brand/inspection.webp` (한 장) | `/brand/svc-care.jpg` · `/brand/svc-bnb.jpg` (**두 장**) |

`public/brand/` 에 있는 것은 여섯 개뿐이다: `favicon.png` `hero-main.jpg` `logo-mark.png`
`svc-bnb.jpg` `svc-care.jpg` `svc-iot.jpg`.

**요청 화면은 장수까지 어긋났다.** 시안은 같은 사진을 두 자리에 쓰는데, 29-6 이 자리마다 다른
파일을 골라 서로 다른 사진 두 장이 됐다.

고를 수 있는 길은 둘이다.

1. 시안의 이미지 네 개를 우리 저장소로 가져와 시안과 똑같이 보이게 한다.
2. 지금의 우리 브랜드 사진을 그대로 둔다 — 그러면 시안과 그림이 다른 것을 받아들이는 것이다.

이건 디자인 결정이라 내가 정하지 않는다.

## 4. 견주지 않은 것

| 무엇 | 왜 |
|---|---|
| 로그인·가입 화면 | 시안은 ChatGPT 로그인, 우리는 우리 것 — 일부러 다르다 |
| 로그인해야 보이는 화면 | GET 만 하므로 양쪽 다 게이트 화면을 받는다 |
| 색·간격·글꼴 등 눈에 보이는 모양 | 글자만 견줬다. CSS 와 실제 렌더는 사람이 봐야 한다 |
| 사진의 내용 | 파일 이름이 다른 것까지 확인했고, 그림 자체를 열어 보지는 않았다 |

## 5. 남은 문구 — "검토용 서비스"

시안과 우리가 **똑같이** 갖고 있다. 이식이 충실해서 그대로 따라온 것이고, 프로덕션 전환
직전에 걷어야 한다. 다섯 자리다.
