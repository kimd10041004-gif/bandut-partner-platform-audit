**랜딩 → 위저드 4단계 등록 → 파트너 입찰 → 고객 견적 수락 → 방문 예약 → 시공 시작 → 체크리스트 → 추가 작업 승인 요청 → (고객 미결정 상태에서 작업 완료 시도 → 도메인 규칙이 차단하는지) → 고객 승인 → 완료 → 정산 → 리뷰 작성 → 관리자 관제(수수료·리뷰·타임라인) → 새로고침 영속성** — **22/22 PASS**. 모바일(390px) 가로 스크롤 없음 확인.

**전 여정이 실제로 작동한다.** 다만 실사용 관점의 결함 3건을 항목화한다.
