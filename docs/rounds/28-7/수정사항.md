# 28-7 수정사항 — 28-6 감사결과 4개 항목 전부 처리 (기획 시안 정렬 라운드)

작업 방식: 기존 규칙 그대로 — 28-1~28-6은 일절 수정하지 않고 스크래치 복사본(`scratchpad/wf28-7`)에서 수정 후 `28-7` 스냅샷 생성. 정렬 기준은 루트 `기획시안_분석.md` (사용자 공유 시안 5장).

## 항목별 수정 내용

### 28-6-01 [상] 입찰 마켓플레이스 정렬 → 수정
- 상태 머신에 **`lost`(미낙찰)** 추가: `estimated → lost` (종결 상태). requested/accepted 등에서는 불가.
- 일감에 **`budget`(예산)**·**`bidDeadline`(입찰 마감)** 선택 필드 추가 — 등록·백업 가져오기 모두 검증(정수 예산, 실제 달력 마감일).
- UI 재구성 (시안 파트너 앱 구조): 탭을 **대시보드 / 일감·입찰 / 내 작업 / 일정 / 정산**으로 재편.
  - 일감·입찰: 예산·D-day가 표시되는 일감 카드 + "입찰하기" 폼(제안 금액 구성 + 고객 메시지) + 입찰 중 일감의 낙찰/미낙찰 처리(고객 결정 시뮬레이션).
  - 용어를 시안과 일치: 입찰 가능/입찰 중/낙찰/미낙찰/방문 예정/시공 중/작업 완료/정산 완료.
  - 대시보드에 **입찰 가능·입찰 중 건수** 표시.
- 회귀 테스트: 예산·마감 저장/검증, lost 전이 규칙(플랫폼·상태 머신 양쪽) — 6개.

### 28-6-02 [상] 추가 작업 승인 → 신규 구현
- `approveExtraWork(requestId, {amount, memo, approvedDate?})`: **시공 중(in_progress)에만**, 1 이상 정수 금액·실제 달력 승인일 검증, `EW-####` id로 영속화.
- `completeJob`: 최종 총액 = 낙찰 견적 총액 + 추가 작업 합계, **수수료는 최종 총액 기준 재산정**, `extraTotal` 기록.
- UI: 내 작업 탭의 시공 중 카드에 추가 작업 승인 폼 + 승인 내역 표시. 시드 이력에도 추가 작업 1건 포함(정산 표에서 반영 확인 가능).
- 회귀 테스트: 총액·수수료 반영(275,000+50,000→325,000, fee 9,750), 상태 제한, 금액·날짜 검증, 백업 round-trip, 오염 데이터 거부 — 5개.

### 28-6-03 [상] 수수료율 3% 정정 → 수정
- `PLATFORM_FEE_RATE` 0.05 → **0.03** (시안 확정값). 파생 기대값(견적/정산/월별 리포트/영속화 테스트) 전부 갱신. UI 문구도 "수수료 3%" 명시.

### 28-6-04 [중] 스냅샷 하위 호환 → 수정
- 신규 필드 `extraWorks`/`extraSeq`는 **선택적** — 구(28-6 이전) 스냅샷은 그대로 복원되고 기본값(빈 목록)이 채워진다. `CompletedJob.extraTotal`도 선택적.
- 회귀 테스트: 필드 없는 구 스냅샷 복원, 오염된 extraWorks 거부 — 2개.
