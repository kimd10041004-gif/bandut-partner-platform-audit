## 4. e2e 여정에 더한 단언

- 낙찰 직후: 예약금 카드 없음 + 계약서 대기 안내.
- 파트너 일정 탭: 조건 없이 "계약서 보내기" → 거절 · 조건·예약금 30,000 → "계약서 v1" 문구 + `[data-contract-fee]`에 "v1 고객 확인 대기" ·
  내 작업 `[data-contract-hint]`에 v1.
- 고객: `[data-contract]` 카드에 30,000·3%·14:00~16:00·조건 · 체크 전 "계약 동의" 비활성 · "수정 요청" → 카드 사라짐 → 파트너 알림
  "v1 수정을 요청" · 파트너가 v2 발송 · 고객 체크 → 동의 → 14:00 + "계약 v2 동의됨" 카드 + 예약금 카드(계약 v2 · 30,000) → 결제 → 영수증.
- 파트너: 일정 변경 제안(D+3 9~11, 사유) → `[data-schedule-pending]` · 고객 `[data-schedule-change]` 카드 → 거절 → 기존 D+1 10:00 유지 ·
  파트너 알림 "일정 변경을 거절".
- 주방 수전: 파트너2 계약서 v1 → 고객 동의 → 방문 예정 10:00 → 예약금(비워서 10%) → (종전) 취소·환불 경로.
