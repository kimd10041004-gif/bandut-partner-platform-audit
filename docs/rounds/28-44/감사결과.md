### 28-44-01 · 운영 큐 도메인
→ 요구: `PlatformService.opsQueue(today)` — ① `overdueRequests`: 마감 경과 & 낙찰 전(견적 수 포함) ② `staleScheduled`: 방문일이 오늘 이전인데 아직 scheduled(시공 미시작) ③ `unpaidCompleted`: completed & 최종 결제 없음(완료 후 경과일) ④ `openClaims`: open/in_review ⑤ `pendingPayouts`(기존). 각 목록은 오래된 순, `counts` 포함. `sweepPaymentReminders(today)` — 완료 후 **3일** 지나도 미결제면 고객·관리자 알림 1회(`paymentReminderFor` 플래그, 멱등). `sweepDeadlines`는 견적 0건 마감 경과를 **관리자에게도** 알림. 스냅샷 검증 + **도메인 테스트 필수**(시간 주입).

→ 요구: 현황 탭 최상단에 **조치 필요** 카드: 승인 대기 파트너(auth) · 마감 경과 요청 · 방문일 경과 미시작 · 결제 지연 · 미해결 A/S·분쟁 · 지급 대기 — 항목별 건수 + 목록(요청 id·설명·경과일) + **바로 처리**(승인 대기: 승인 버튼 / 지급 대기: 지급 완료 버튼, 계좌 없으면 오류) + 나머지는 해당 탭 안내. 전부 0건이면 "오늘 처리할 항목이 없습니다".
