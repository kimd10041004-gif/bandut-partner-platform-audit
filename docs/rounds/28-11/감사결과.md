## 중 (Medium)

### 28-11-01 · 다크 모드 부재
현장 파트너는 이른 아침·저녁 이동 중 사용이 잦다. tokens.css 분리(28-10-03) 덕분에 다크 팔레트는 이제 토큰 오버라이드만으로 가능하다.
→ 요구: `[data-theme='dark']` 토큰 오버라이드 + 시스템 추종(`prefers-color-scheme`, 명시 선택이 우선) + 헤더 토글 버튼(달/해 아이콘) + 선택 영속화(localStorage, try/catch). 상태 칩·표·그림자까지 다크에서 대비 유지.

### 28-11-02 · 일감 검색·필터 부재
시안 '일감 찾기'에는 키워드·지역·카테고리 검색이 명시돼 있다. 일감이 쌓이면 목록 스캔이 불가능해진다.
→ 요구: 일감·입찰 탭에 키워드 검색(요청 내용·고객명·지역 대상)과 카테고리 필터 툴바. 결과 0건일 때 빈 상태 안내.

### 28-11-03 · 입찰 성과 지표 부재
시안 대시보드/프로필에는 낙찰 확률·응답 지표가 있다. 현재는 파트너가 자신의 입찰 성과를 볼 수 없다.
→ 요구: 도메인 헬퍼 `bidStats()` — 총 입찰 수, 낙찰(accepted 이후 도달), 미낙찰, 대기, **낙찰률(결정된 건 기준)**. 도메인 레벨 테스트 필수. 마이 탭 프로필 카드에 표시.
