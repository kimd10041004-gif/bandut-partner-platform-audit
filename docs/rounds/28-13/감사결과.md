# 28-13 감사결과 (GPT 역할 — Claude 세션 대리 수행)

감사 범위: `28-13` 전체 — **사용자 지시 "틀을 전체적으로 다 잡자"에 따라, 이번 감사는 틀(토큰·부품·셸·게이트·문서)의 남은 격차를 전수 항목화한다.**
사전 확인: `tsc --noEmit` 0 오류, vitest 130/130, node --test 7/7, visual-check 전 항목 PASS, 프로덕션 배포 그린(PR #12 머지). 28-12 감사 4건 전부 수정 확인됨.

## 상 (High — 틀)

### 28-13-01 · 토큰 체계 미완 — 색만 토큰이고 간격·모션은 하드코딩
tokens.css는 색·타이포·형태만 다룬다. components.css에는 px 값이 산재하고(1px×21, 5px×14, 2px×12, 14px×9 …), transition 시간도 0.12/0.15/0.18/0.2s **4종이 파일 곳곳에 흩어져** 있다. 간격·모션이 토큰이 아니면 "틀에서 한 번에 바꾼다"가 성립하지 않는다.
→ 요구: 간격 스케일(`--sp-*`)과 모션 토큰(`--dur-fast/base`, `--ease`)을 팔레트/시맨틱 구조에 추가하고, components.css의 **정확히 일치하는 값**부터 토큰 참조로 치환(컴포넌트 고유 미세값은 잔류 허용, 잔류 사유 명시). 렌더 결과 동일성은 visual-check로 증명.

### 28-13-02 · 컴포넌트 레시피가 문서에만 있고 부품이 아님
DESIGN_SYSTEM.md 인벤토리 12종 중 실제 재사용 부품(primitives)은 4종뿐. 카드 마크업(`<div className="card"><h3>…`)이 features 5개 파일에서 10회 반복된다. 레시피가 부품이 아니면 룩 변경 시 10곳을 고치게 된다.
→ 요구: `ui/primitives.tsx`에 `Card`(제목+본문) 및 `Stat`(톤·아이콘·라벨·값) 부품 승격, features 전체를 부품 사용으로 전환. **렌더 DOM 구조 동일 유지** — 시각 회귀는 visual-check로 증명.

### 28-13-03 · 오류 격리 틀 부재 — 예상외 오류 시 백화면
`isKnownError()` 규약상 도메인 외 오류는 rethrow 되는데, 이를 받아줄 React ErrorBoundary가 없다 — 탭 하나의 예외가 앱 전체 백화면이 된다. 견고한 셸은 틀의 일부다.
→ 요구: `app/ErrorBoundary.tsx` — 활성 탭 렌더를 감싸고, 실패 시 오류 메시지 + "새로고침" 안내 카드 표시(다른 탭·헤더는 생존). 탭 전환 시 오류 상태 리셋.

## 중 (Medium)

### 28-13-04 · 접근성 틀 최소선 미충족
탭 내비에 `aria-current` 없음, 본문 바로가기(skip link) 없음, `<main>`에 id 없음. 시각 틀만큼 접근성 틀도 초기에 잡아야 비용이 낮다.
→ 요구: skip link("본문 바로가기") + `<main id="main">` + 활성 탭 `aria-current="page"` + 테마 토글 `aria-pressed`. 키보드 포커스 링은 기존 `--brand-glow` 재사용.

### 28-13-05 · 품질 게이트가 명령 4개로 분산
typecheck/test/test:node/build를 각각 불러야 한다. 라운드 검증 절차의 진입점이 하나여야 틀이라 할 수 있다.
→ 요구: `npm run check` = typecheck → vitest → node --test → build 순차 실행(하나라도 실패 시 중단). README·UI_가이드에 공식 게이트로 명시(visual-check는 Playwright 필요라 별도 유지).

## 하 (Low)

### 28-13-06 · 루트 README에 틀 문서 지도 부재
DESIGN_SYSTEM.md·UI_가이드.md·visual-check가 생겼지만 루트 README는 이를 안내하지 않는다 — 처음 여는 사람이 틀 문서를 발견할 수 없다.
→ 요구: README에 "틀 문서 지도" 섹션(무엇을 보려면 어느 문서인가) + `npm run check` 반영.
