## 항목별 수정 내용

### 28-17-01 [상] 리뷰 도메인 → 신규 구현
- `Review { requestId, rating(1~5 정수), text, createdDate }`. `writeReview()`: completed/settled에서만, 요청당 1건(중복 오류), 별점 범위 검증. `reviewFor()`/`allReviews()`(최신순)/`reviewStats()`(건수·평균 소수 1자리, 없으면 null).
- 스냅샷 `reviews?` 필드 — 구 스냅샷 하위 호환 + 요소 검증(rating 범위·날짜 형식). 회귀 테스트 3개(상태·범위·중복 / 평균 집계 / 스냅샷 왕복·불량 거부) → vitest 142→145.

### 28-17-02 [상] 고객 리뷰 작성 → 신규 구현

- 타임라인에 "리뷰 작성 (★n)" 이벤트 추가(리뷰 있을 때만, 작성일 포함).

### 28-17-03 [상] 파트너 평판 → 신규 구현

### 28-17-04 [중] 관리자 리뷰 관리 → 신규 구현
