# 28-18 감사결과 (GPT 역할 — Claude 세션 대리 수행)

감사 범위: `28-18` 전체 — **사용자 지적 "너무 AI가 만든 것 같아. 당근을 보고 본받자" + 레퍼런스 3종 재대조** (당근 seed-design / naver design-to-ui / bear2u).
사전 확인: `npm run check` exit 0 (vitest 145/145, node --test 7/7), visual-check 전 항목 PASS, 프로덕션 배포 그린(PR #27 머지). 28-17 감사 5건 전부 수정 확인됨.

핵심 지적: 기능·틀은 갖췄지만 **룩이 "AI 템플릿 문법"** 이다. 당근의 실제 문법과 정반대인 지점들:

| AI 템플릿 문법 (현재) | 당근 문법 (목표) |
|---|---|
| 네이비 그라데이션 헤더·히어로, 3색 그라데이션 서비스 카드, 로고 그라데이션 | **그라데이션 없음** — 플랫 서피스(흰 헤더+헤어라인), 강조색은 CTA에만 |
| 지표 타일마다 파랑/초록/주황 아이콘 칩 | 숫자 우선 — 라벨(회색 캡션) 위, 큰 숫자(잉크) 아래, 장식 없음 |
| 카테고리 카드의 이니셜 마크(도/장/욕…) | 텍스트 필(pill) 칩 — 가짜 아이콘보다 정직한 텍스트 |
| 그림자 떠 있는 카드 범벅 | 보더 1px + 헤어라인 구분선, 그림자 최소 |
| "✓ 등록 무료" 같은 ✓ 텍스트 장식 | 담백한 텍스트 + · 구분 |

## 상 (High)

### 28-18-01 · 그라데이션·장식 전면 제거 (탈 AI 룩의 핵심)
→ 요구: 헤더를 **흰 서피스 + 하단 헤어라인**(잉크 텍스트, 플랫 브랜드 마크)으로, 랜딩 히어로를 **페이지 배경 위 초대형 잉크 타이포 + 브랜드 CTA**로, 서비스 카드 3종을 플랫 카드(보더+브랜드 태그)로. 로고 마크 플랫화. DESIGN_SYSTEM Identity의 금지 규칙을 "그라데이션 전면 금지"로 강화. 다크 모드는 토큰 경유로 자동 유지.

### 28-18-02 · 지표 타일의 대시보드 템플릿 룩 제거
→ 요구: `Stat` 부품에서 색 아이콘 칩 제거 — 라벨(캡션·muted) 위 + 값(display·ink) 아래, 강조 타일만 브랜드 색 값. 보더 1px, 그림자·리프트 제거.

### 28-18-03 · 카테고리 그리드를 텍스트 필로
→ 요구: 랜딩·위저드의 카테고리를 이니셜 마크 카드 → **텍스트 필 칩**(당근 카테고리 칩: 보더 필, hover=잉크 보더, 선택=브랜드)으로 교체.

## 중 (Medium)

### 28-18-04 · 리스트 행 패턴 부재
당근 UI의 중추는 리스트 행(제목 15/600 + 보조 13 muted + 우측 값, 헤어라인 구분)이다. 현재는 meta 텍스트 뭉치.
→ 요구: `.list-row` 패턴 도입 — 대시보드 일정 목록·마이 리뷰 목록·견적함 결정 내역에 적용.

### 28-18-05 · 카드·버튼·칩 플랫화
→ 요구: 카드=보더 1px·그림자 제거(hover는 보더 강조만), 보조 버튼=회색 배경(보더 없음), ✓ 텍스트 장식 제거(트러스트 배지·서비스 불릿), 표·칩의 잔여 그림자 정리.
