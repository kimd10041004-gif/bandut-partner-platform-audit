# 28-1 구축내역 — 반듯집수리 파트너 플랫폼 (GitHub 신규 시리즈)

## 배경

기존 맥 데스크탑의 "반듯 집수리 클로드 27 ver." 원바이원 라운드 루프를 GitHub 저장소 기반으로 새로 시작하는 첫 라운드. 사용자 결정에 따라:

- 기존 데스크탑 폴더는 **일절 건드리지 않는다** (이 저장소는 별도 신규 구축).
- 방법론은 기존 방식과 **동일**하게 유지한다: 라운드 폴더 스냅샷, 감사결과/수정사항/검증결과 문서, 복사본 작업, 해시 무결성 증명, 수치는 명령 출력 인용.
- GPT(Codex) 감사자 역할은 이 Claude 세션이 **대리 수행**한다.

## 구성

| 영역 | 내용 |
|---|---|
| 스택 | TypeScript 5.7 (strict), Vite 6 + React 18, vitest 2, node:test |
| `src/domain/types.ts` | 요청/견적/일정/정산 도메인 타입 |
| `src/domain/estimate.ts` | 견적 계산 (정수 원 단위, VAT 10%, 플랫폼 수수료 5%, 검증) |
| `src/domain/jobStatus.ts` | 8단계 상태 전이 머신 (허용 전이 화이트리스트) |
| `src/domain/schedule.ts` | 방문 일정 슬롯 검증·충돌 감지 |
| `src/domain/settlement.ts` | ISO 주차(UTC) 기준 주간 정산 집계 |
| `src/domain/store.ts` | 인메모리 요청 저장소 (방어적 복사, 전이 규칙 강제) |
| `src/App.tsx` | 파트너 UI: 요청 목록/견적 계산/일정/정산 4탭 |
| `scripts/format.mjs` | 표시용 포맷 유틸 (플레인 ESM — node --test 러너 대상) |
| 테스트 | vitest `src/**/*.test.ts` + node --test `tests/node/**/*.test.mjs` (이중 러너, 기존 방식 유지) |
