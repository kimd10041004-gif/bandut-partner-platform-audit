`platform.test.ts`(describe "28-96")를 이 라운드의 바탕인 `round-28-95` 머리(`d798376`, = 병합 뒤 `main e405ebd`) 워크트리에 얹어 돌렸다:

```

 × 스냅샷 검증: 공급가·VAT·합계가 어긋나면 거절
 × 작업 전 사진: 낙찰 파트너만, 방문 예정부터 최종 결제 전까지, 용량·정리·개수에 포함

PlatformError: 추가 작업 금액은 1 이상의 정수(원)여야 합니다: undefined

      Tests  4 failed | 224 skipped (228)
```

첫 줄: 바탕에서 `supply`는 무시되고 `amount`가 없다고 거절된다(공급가·VAT라는 것이 없다). 마지막 줄: 계약 작업이 사진 없이 완료된다.
28-95의 테스트 하나("계약 결정 … 수수료 = 계약 bps")가 계약 작업을 사진 없이 완료하고 있어 전/후 사진을 넣어 고쳤다.

e2e가 잡은 것: 관리자 저장 용량 카드의 "사진 3장" 단언 — 작업 전 사진이 더해져 4장이 됐다(현장 2 + 작업 전 1 + 완료 1). 최종 결제
금액도 추가 작업 70,000 → 77,000(VAT 포함)으로 `322,000`이 됐다(275,000 + 77,000 − 계약 예약금 30,000).

  승인 뒤 "+77,000".
- 작업 전 사진 없이 "→ 작업 완료" → "작업 전 사진과 완료 사진을 각각 1장 이상" 차단 → `aria-label="작업 전 사진"` 첨부 → `[data-before]`
  썸네일 1 → 완료.
- 고객 거래 상세: 작업 전 1장 + 완료 1장. 관리자 저장 용량 사진 4장. 최종 결제 322,000.
