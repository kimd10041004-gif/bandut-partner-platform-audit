# 28-96 수정사항 — 추가 공사 공급가+VAT 분리 · 작업 전/후 사진 (참고 v12 대조 6)

`../28-90/참고_v12_대조.md` "더할 것" 6번. 참고 시안은 추가 공사를 **공급가·VAT(10%)·합계**로 나눠 기록하고(`extra_works.supply/vat/total`),
완료 확인 요청에 **작업 전 사진·작업 후 사진을 각 1장 이상** 요구한다(`completions.before_photos/after_photos`, `complete`). 28-95까지
우리는 추가 작업을 VAT 포함 금액 하나로 받았고, 완료 사진은 "완료 사진" 한 묶음이었으며 완료에 사진이 필요 없었다.

## A. 도메인

- `ExtraWork.supply?`·`vat?` — `requestExtraWork({ supply, memo })`가 `vat = round(supply × 10%)`, `amount = supply + vat`로 기록한다.
  `{ amount }`만 주는 구 호출은 VAT 포함 금액으로 그대로(구 데이터와 같은 모양). 알림 문구에 공급가·VAT를 함께 적는다. 스냅샷 검증은
  셋이 있으면 서로 맞아야 한다(`금액 불일치`).
- `RepairRequest.beforePhotos?` + `setBeforePhotos(requestId, partnerId, photos)`: 낙찰 파트너만, **방문 예정~작업 완료**(최종 결제 전),
  같은 사진 규칙(3장·200KB)과 용량 가드. `storageUsage`·`prunePhotos`·본인/파트너 반출의 `photoCount`에 포함.
- **`completeJob`**: 동의된 계약(28-95)이 있는 작업은 작업 전 사진과 완료 사진이 각 1장 이상 있어야 완료된다 — 계약 없는 구 경로(테스트
  픽스처·구 데이터)는 종전대로 사진 없이 완료된다. 28-95의 "계약이 오간 요청" 경계를 그대로 쓴다.

## B. 화면

- **파트너 내 작업**(`Work.tsx`): `CompletionPhotos`를 `JobPhotos kind="before"|"completion"`으로 일반화 — 작업 전 사진
  (`aria-label="작업 전 사진"`, 방문 예정부터)·완료 사진(`aria-label="완료 사진"`, 시공 중부터), 각 `[data-before]`/`[data-completion]` 띠.
  추가 작업 폼은 **공급가**를 받고 `[data-extra-preview]`에 VAT·합계를 보여 준다. 승인된 추가 작업 줄에 `(공급가 + VAT)`.
- **고객 거래 상세**: 작업 전 사진 띠(`[data-before]`) + 완료 사진 띠, 승인 요청 카드에 `[data-extra-vat]`(공급가 + VAT), 결정 내역에도.
- **관리자 거래 상세**: 작업 전 사진 띠, 추가 작업 줄에 공급가·VAT.
- `PhotoStrip`에 `before` prop(`[data-before]`).

## C. 하지 않은 것

- 참고안의 **완료 확인 요청 → 고객 확인/보완 요청**(`COMPLETION_REQUESTED`) 단계는 넣지 않았다 — 우리는 파트너 완료 → 고객 최종 결제가
  확인 역할을 한다(사진은 결제 전 열람). 필요하면 다음 라운드.
- 계약 없는 구 경로에는 사진 필수를 걸지 않았다(A 참조).
- 추가 작업의 사진 첨부(참고안 `photo_ids`)는 없다 — 완료 사진으로 갈음.
