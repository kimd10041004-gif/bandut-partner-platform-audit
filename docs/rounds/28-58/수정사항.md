## 28-57-01 운영 감사 로그 (상)
- `types.ts`: `AuditEntry { id: 'AUD-00001', at, actor: 'admin'|'system', action, target, detail? }`.
- `platform.ts`: 스냅샷 `auditLog/auditSeq` + 검증(actor 두 값만, id/at/action/target 문자열, detail 문자열). `AUDIT_RETENTION_DAYS = 180`, `AUDIT_CAP = 1000`.
  - `private record(actor, action, target, detail?)`: 행위와 **같은 `save()` 안**에 기록 — `markPayout`(지급 완료: 금액·계좌), `settleRefund`(환불 완료: 요청·실환불액·차감), `reviewClaim`(검토 시작), `resolveClaim`(해결 처리: 처리 내용), `updateSettings`(설정 변경: 바뀐 키), `addPackage/updatePackage/removePackage`, `addQuestion/removeQuestion`.
  - 시스템 정리: `sweepDeadlines`(마감 정리)·`sweepPaymentReminders`(결제 리마인더)·`sweepVisitReminders`(방문 리마인더)·`prunePhotos`(사진 정리)·`pruneNotifications`(알림 정리)·`pruneChats`(채팅 정리) — `n > 0`일 때만 `actor: 'system', target: String(n)`.
  - `audit(actor, action, target, detail?)`: 인증 서비스(다른 서비스) 행위를 UI가 기록 — 즉시 저장, 빈 행위·대상 거부.
  - `auditLog(limit?)` 최신순. `pruneAuditLog(now)`: 180일 경과 제거 → 상한 초과분 오래된 것부터, 제거 수 반환(멱등). `bootstrap`·관리자 현황 sweep에 포함.
- `AdminMembers`/`AdminOverview`: 파트너 승인·거절·기록 파기·계정 정지/해제 후 `platform.audit('admin', …)`.
