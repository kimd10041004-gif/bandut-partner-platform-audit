# 28-26 감사결과 (GPT 역할 — Claude 세션 대리 수행)

감사 범위: `28-26` 전체 + 상세시안 로드맵 대조(다음 순서: 동적 질문 빌더 — 시안 3 CMS의 마지막 잔여).
사전 확인: `npm run check` exit 0 (vitest 156/156), e2e 26/26 PASS, visual-check 전 항목 PASS, 프로덕션 배포 그린(PR #49 머지). 28-25 감사 5건 전부 수정 확인됨.

가격 패키지까지 닫혀 CMS 묶음이 거의 완결됐다. 남은 마지막 조각은 **질문 빌더**다: 지금 위저드는 어떤 카테고리를 골라도 같은 질문(내용·주소·일정·예산)만 묻는다. 시안 3의 질문 빌더는 "카테고리별 맞춤 질문"으로 견적 정확도를 올리는 장치다 — 욕실이면 방수 상태를, 전기면 차단기 위치를 미리 물어야 파트너가 방문 전에 정확한 금액을 제안할 수 있다. 질문 답변이 파트너에게 전달되지 않으면 아무 소용이 없으므로, 수집→저장→노출 전 구간을 요구한다.

---

## 상 (High)

### 28-26-01 · 질문 빌더 도메인 부재 (시안 3 "질문 빌더")
→ 요구: `CategoryQuestion { id, category, label, options?, active }` — options가 있으면 선택형, 없으면 단답형.
- `addQuestion()`: 질문 공백 거부, 카테고리는 ALL_CATEGORIES 내만, options는 있으면 **2개 이상**·공백 항목 거부.
- `toggleQuestion(id)` / `removeQuestion(id)` — 없는 id 거부. `listQuestions()`(관리자용 전체) / `questionsFor(category)`(위저드용 — active만).
- 카테고리별 기본 질문 시드(최소 3개 카테고리). 스냅샷 `questions?`+`questionSeq?` 하위 호환 + 요소 검증 + **도메인 테스트 필수**.

### 28-26-02 · 요청에 답변이 실리지 않음
→ 요구: `RepairRequest.answers?: { question, answer }[]` — 질문 **텍스트를 복사 저장**(이후 질문이 수정·삭제돼도 과거 요청 기록 불변). `addRequest` 입력에 answers 추가(빈 답변은 제출 시 제외), 스냅샷 요소 검증. 위저드 1단계(작업 내용)에서 선택한 카테고리의 활성 질문을 렌더(선택형은 버튼 필, 단답형은 input) — 답변은 선택 사항.

### 28-26-03 · 파트너·거래 상세에 답변 미노출
→ 요구: 파트너 일감 카드에 답변 요약 노출(입찰 전 정보 — 이 라운드의 존재 이유), 고객 거래 상세에도 표시.

## 중 (Medium)

### 28-26-04 · 관리자 질문 관리 UI
→ 요구: 관리자 설정 탭 "질문 빌더" 카드 — 카테고리별 목록(선택형 옵션 표시·활성 상태), 추가 폼(카테고리/질문/선택지 쉼표 구분·비우면 단답형), 활성 토글·삭제.

### 28-26-05 · e2e + 실측
→ 요구: e2e에 "위저드에서 카테고리 질문 답변 → 파트너 일감 카드에 노출" 추가(기존 26단계 무회귀), 위저드 질문·관리자 질문 빌더 스크린샷 실측.
