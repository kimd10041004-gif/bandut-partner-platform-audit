시안 3("관리자 CMS·운영 설정")의 잔여인 **가격 패키지**를 도메인→관리자 CRUD→고객 노출까지 연결해 CMS 묶음을 닫는다.

## 28-25-01 · 가격 패키지 도메인 [반영]

- `types.ts`에 `ServicePackage { id, name, category, price(정수 KRW), description, active }`.
- `platform.ts`:
  - `DEFAULT_PACKAGES` 시드 6종(욕실/수전·배수/전기/문·도어락/방충망/스마트홈) — 홈페이지가 비어 보이지 않는 출발점, 관리자가 수정·숨김·삭제 가능.
  - `addPackage()` — 이름 공백 거부, 가격은 **1원 이상의 정수**(0·음수·소수 거부), 카테고리는 ALL_CATEGORIES 내만. ID `PK-####` 시퀀스.
  - `updatePackage(id, patch)`(등록과 동일 검증) / `togglePackage(id)` / `removePackage(id)` — 없는 id는 "찾을 수 없습니다" 거부.
  - `listPackages()`(관리자용 전체, 등록순) / `activePackages()`(고객용 — active **그리고** 카테고리 활성).
  - 스냅샷 `packages?`+`packageSeq?`: 없으면 기본 시드로 복원(구 스냅샷 하위 호환), 있으면 요소 검증(카테고리·정수 가격·boolean active). 직렬화에 포함.
- 도메인 테스트 4건 추가(시드·등록 검증 / 수정·토글·삭제·없는 id / activePackages 제외 규칙 / 스냅샷 왕복·구 스냅샷·손상 거부) → vitest 152→**156**.

## 28-25-02 · 관리자 패키지 관리 UI [반영]

- `AdminSettings.tsx`에 "가격·패키지 관리 (N건)" 카드 — 목록(카테고리 필 `svc-tag`·정찰가·숨김 표시·설명), 행별 **숨김/노출** 토글·**삭제**, 하단 등록 폼(이름/카테고리 select/정찰 가격/설명). 가격 입력은 `parseWonInput` 재사용, 도메인 오류 메시지를 그대로 표시(기존 `apply()` 패턴).

## 28-25-03 · 고객 웹 표준 가격 [반영]

- `Landing.tsx`에 "표준 가격" 섹션(서비스 카드와 FAQ 사이) — `activePackages()`를 `.list-row` 플랫 문법(카테고리 텍스트 필 + 우측 정찰가)으로 노출, "표준 시공 기준 정찰가입니다. 정확한 금액은 견적에서 확정됩니다." 고지. 활성 패키지가 0이면 섹션 자체를 숨김. 카테고리 토글과 자동 연동(28-25-01의 activePackages 규칙).
