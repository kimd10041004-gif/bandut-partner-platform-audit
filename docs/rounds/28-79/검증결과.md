### 28-79-01 시연 지표

수정 전, 부팅 경로를 그대로 태워 **첫 방문자가 보는 값**을 뽑았다(이 출력이 감사 01의 근거다):

```
누적 요청 6 | 완료된 수리 3 | 낙찰률 100 | 평균 만족도 null
```

수정 뒤, 같은 빌드를 실제 브라우저로:

```
오류: 0 | 히어로 지표 노출: false
누적/낙찰률 문구 존재: false
실제 요청 추가 뒤 지표 노출: true
```

도메인 회귀 2건(`시연 시드만 있으면 hasRealActivity()가 false다`, `실제 요청이 하나라도 생기면 true`)과
부팅 회귀 1건(`부팅 직후에는 시연 시드뿐이라 실적이 없다`)은 **수정 전에는 성립할 수 없다** — `seeded`
표식도 `hasRealActivity()`도 없어서 타입 단계에서 막힌다. e2e 여정 단계도 추가했다:

```
PASS  첫 방문(시연 데이터뿐): 히어로 실적 지표가 없다 (28-79-01)
```
