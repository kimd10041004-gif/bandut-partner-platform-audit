# 28-27 수정사항 (Claude) — 동적 질문 빌더 라운드

기반: `28-26` 복사본(스크래치 wf28-27)에서 작업. 28-26 감사 5건 전부 반영.
시안 3("관리자 CMS·운영 설정")의 마지막 잔여인 **질문 빌더**를 수집→저장→노출 전 구간으로 연결해 CMS 묶음을 완결한다.

## 28-26-01 · 질문 빌더 도메인 [반영]

- `types.ts`에 `CategoryQuestion { id, category, label, options?, active }` — options가 있으면 선택형(2개 이상), 없으면 단답형.
- `platform.ts`:
  - `DEFAULT_QUESTIONS` 시드 6종(욕실 2·전기 2·도배 1·누수 1, 선택형·단답형 혼합).
  - `addQuestion()` — 질문 공백 거부, 미지 카테고리 거부, 선택지는 트리밍 후 1개면 "2개 이상" 거부(전부 비면 단답형 처리). ID `Q-####` 시퀀스.
  - `toggleQuestion(id)` / `removeQuestion(id)`(없는 id 거부) / `listQuestions()`(관리자용) / `questionsFor(category)`(위저드용 — active만).
  - 스냅샷 `questions?`+`questionSeq?`: 없으면 시드 복원(하위 호환), 있으면 요소 검증(라벨·카테고리·options 2개 이상·boolean active).
- 도메인 테스트 3건 추가.

## 28-26-02 · 요청에 답변 탑재 [반영]

- `RepairRequest.answers?: RequestAnswer[]` — **질문 텍스트를 복사 저장**(질문이 이후 수정·삭제돼도 과거 요청 기록 불변).
- `addRequest`: 질문 텍스트 공백 거부, 답변 트리밍 후 **빈 답변은 걸러서** 저장(전부 비면 answers 자체 미탑재). 스냅샷 요소 검증(`requests[i].answers`).
- 위저드 1단계: 선택한 카테고리의 `questionsFor()` 렌더 — 선택형은 필 버튼(재클릭 시 해제), 단답형은 input, 전부 선택 사항. 카테고리를 바꾸면 그 카테고리의 질문으로 교체. 도메인 테스트 1건 추가 → vitest 156→**160**.

## 28-26-03 · 파트너·거래 상세 노출 [반영]

- 파트너 일감 카드: 답변을 `.qa-line`("질문 — 답변")으로 입찰 전 노출.
- 고객 거래 상세(CustomerHome): 동일 표기로 요청 헤더 아래 표시.

## 28-26-04 · 관리자 질문 관리 UI [반영]

- 설정 탭 "질문 빌더 (N건)" 카드 — 카테고리 필·선택형/단답형 표기·숨김 상태, 행별 숨김/노출 토글·삭제, 등록 폼(질문/카테고리/선택지 쉼표 구분 — 비우면 단답형). 오류는 도메인 메시지 그대로.

## 28-26-05 · e2e + 실측 [반영]

- e2e에 1단계 추가(26→**27**): 위저드에서 "곰팡이 있음" 답변 → "카테고리 질문 답변이 일감 카드에 노출". 기존 26단계 무회귀.
- 실측: 위저드 질문(선택형 활성 + 단답형 입력), 일감 카드 답변 노출 true, 관리자 질문 빌더(등록 후 7건) 스크린샷 3종.
