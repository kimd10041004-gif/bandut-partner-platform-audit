작업 방식: 기존 규칙 그대로 — 28-1~28-19는 일절 수정하지 않고 스크래치 복사본(`scratchpad/wf28-20`)에서 수정 후 `28-20` 스냅샷 생성. 사용자 질문 "정말 다 작동돼?"에 대한 실사용 전수 점검(28-19/감사결과.md)에서 나온 결함 수정.

## 항목별 수정 내용

### 28-19-01 [상] 모바일 헤더 줄바꿈 → 수정
- 역할 스위처 버튼·앱 제목 `white-space: nowrap`. 480px 이하: 라운드 칩 숨김 + 헤더 간격·패딩 축소 + 스위처가 우측 정렬 승계 + 버튼 패딩 축소.
- 실측: 390px에서 스위처 버튼 높이 < 40px(한 줄) 검증을 e2e에 편입.

### 28-19-02 [중] 방문 예약 시간 select → 수정
- 일정 탭 시작/종료 시각을 자유 숫자 입력 → **08:00~19:00 select**로 교체. 도메인 검증(parseHourInput·슬롯 충돌)은 그대로 유지.

### 28-19-03 [중] 실사용 여정 검증 공식화 → 신규 구현
- `scripts/e2e-journey.mjs` + `npm run e2e` — UI만 눌러서 수행하는 전 여정 14단계:
  랜딩 → 고객 위저드 등록 → 파트너 입찰 → 고객 수락 → 방문 예약(select) → 시공 시작 →
  추가 작업 승인 요청 → **미결정 상태 완료 차단 확인** → 고객 승인(+70,000 반영) →
  완료 → 정산 → 리뷰 → 관리자 관제 → 새로고침 영속성 → 모바일 가로 스크롤·스위처 한 줄.
  실패 시 비정상 종료 — visual-check와 함께 라운드 공식 게이트.
