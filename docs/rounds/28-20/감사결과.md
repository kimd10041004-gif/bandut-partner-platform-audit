### 28-20-01 · 진입점 분리 — 역할 스위처 병합 해체
→ 요구: **해시 기반 앱 분리** — `#/`(고객 웹: 랜딩+홈·수리 요청·견적함), `#/partner`(파트너 센터), `#/admin`(관리자 콘솔). 딥링크·새로고침 시 해당 앱 유지, 브라우저 뒤로 가기 동작. 헤더의 역할 스위처 **제거**(CSS 포함). 도메인·데이터는 공유(동일 localStorage — 한 플랫폼의 세 얼굴).

→ 요구: 파트너·관리자 헤더에 앱 뱃지("파트너"/"관리자") + "← 고객 홈" 복귀 링크. 고객 랜딩 하단에 실서비스 관례대로 **"사업자이신가요?" 섹션**(파트너 센터 → / 관리자 콘솔 →). 브랜드 클릭은 자기 앱의 홈으로(고객=랜딩, 파트너/관리자=첫 탭).
