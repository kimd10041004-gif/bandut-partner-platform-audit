## 중 (Medium)

### 28-5-01 · 완료된 시공의 슬롯이 '오늘/다가오는 일정'에 상태 구분 없이 계속 표시됨
`upcomingSlots()`와 대시보드 오늘 일정이 요청 상태를 보지 않는다. 이미 완료 처리한 방문이 남은 방문과 똑같이 표시되어, 파트너가 대시보드에서 "아직 가야 할 곳"을 구분할 수 없다.

재현 (스크래치 vitest):
```
scheduled → in_progress → completed 처리한 요청의 미래 슬롯이
upcomingSlots()에 그대로 1건 반환됨 — Tests 2 passed
```
→ 요구: 다가오는 일정은 활성(scheduled/in_progress) 요청의 슬롯만, 오늘 일정에는 상태 라벨을 표시할 것.

### 28-5-02 · 백업 가져오기의 요소 수준 검증 부재 — 오염된 백업이 NaN 정산을 만듦
`parseSnapshot()`이 배열 여부만 검사하고 요소 내용은 검증하지 않는다. `jobs[].total`에 문자열이 든 백업이 그대로 적용되어 정산 집계가 조용히 NaN이 된다.

재현 (스크래치 vitest):
```
importSnapshot({... total: "abc" ...}) 정상 적용 →
settlements()[0].payout → NaN — Tests 2 passed
```
→ 요구: 요청/견적/작업/슬롯 요소별 검증 (정수 금액, 실제 달력 날짜, 허용된 상태값, 슬롯 형식). 검증 실패 시 PlatformError + 기존 데이터 보존. 견적 breakdown은 저장값을 신뢰하지 말고 `calcEstimate`로 재계산할 것.

### 28-5-03 · 매출 리포트 부재
정산 탭이 주차 집계뿐이라 "이번 달 얼마 벌었나"를 답하지 못한다.
→ 요구: 월별 요약(건수/총액/수수료/지급액 + 정산 확정/미정산 분리) 집계를 PlatformService 헬퍼로 제공하고 정산 탭에 표시.
