# 참고 v12 대조 — 없앨 것 · 남길 것 · 더할 것

참고 프로젝트: `bandeut-marketplace-v12` (사용자가 압축 파일 3개로 전달 — 소스 1 + 브랜드 영상 2). Next.js +
Cloudflare D1/R2 + Toss 결제. 사용자 설명: **"너랑 만들고 있는 사이트를 최적화해서 만든 사이트."**
이 문서는 그 시안을 이 저장소와 **기능 단위로** 대조한 결과이고, 28-90의 결정과 그 뒤 라운드의 순서를 정한다.

인증(ChatGPT 헤더)과 스택(D1/R2/Next)은 옮길 수 없다 — 기능과 흐름만 가져온다.

## 2. 남길 것 (참고안에 없거나 약하지만 우리가 더 낫다)

- 관리자 등급 셋(28-89) — 참고안은 관리자 하나.
- 백업·복원·보관함·용량 회계(28-50~28-78) — 참고안은 D1이 알아서 한다고 본다.
- 가명본 내보내기·열람권(28-61~28-63) — 참고안에 없다.
- 계정 잠금·신뢰 IP·세션 해시(28-52·28-70·28-77) — 참고안은 헤더 인증에 기댄다.
- 서버 모드 전환 준비(28-87)·서버리스 가드(28-88) — 우리 배포 모양에만 있는 문제.

돈보다 접수가 먼저인 이유는 잘못 들어온 요청에 결제를 붙여도 환불만 늘기 때문이다.
