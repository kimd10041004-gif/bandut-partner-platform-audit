## 4. e2e 여정에 더한 단언 (`scripts/e2e-journey.mjs`)

- 정산 계좌: 예금주 `김파트너` → 거절 문구 · `반듯설비` → 저장, `data-payout-verified="no"` · 미인증 지급 → `인증되지 않은 정산 계좌` ·
  `[data-verify-payout]` 클릭 → `인증됨` · 지급 성공. 마스킹 예금주는 `(반\*+)`.
- 분쟁: `[data-file-claim]` → 파트너 `분쟁 답변` → 관리자 **분쟁** 탭 해결 → 고객 확인.
- 복원 대조값은 공지 배너(`공지 60` / `공지 45`) — 보증 일수 입력이 없어졌기 때문.
