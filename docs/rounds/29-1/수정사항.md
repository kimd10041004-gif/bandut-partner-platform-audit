# 29-1 수정사항 — v17 도메인 이식 · Postgres 포트

`docs/참고_v17_대조.md` 1번. 참고본 v17의 **서버 계층 전부**를 저장소로 들여오고, 그 도메인이 우리가 쓰는
Postgres에서 그대로 돌게 만든다. 화면과 배포 경로는 이번 라운드에서 건드리지 않는다 — 기존 SPA가 그대로 서빙된다.

## A. 들여온 것 (원본 그대로)

- `lib/` — 도메인(`marketplace/`: 금액·일정·날짜·다음 할 일), 서비스(`service.ts`·`trade.ts`·`community.ts`·
  `workspace-service.ts`·`presentation-service.ts`), 정책(`policy.ts`·`catalog.ts`), 사진 검증(`photos.ts`),
  결제사 어댑터(`payments.ts`), 초안(`draft.ts`).
- `db/sqlite/*.sql` — v17의 drizzle 마이그레이션(표 30·트리거 17). 테스트가 이 파일을 그대로 읽는다.
- `tests/*.integration.test.ts` — v17의 통합 테스트. 경로 두 줄(마이그레이션 위치)만 고쳤다.

**포맷을 고치지 않았다.** 원본과 줄 단위로 대조할 수 있어야 해서 prettier 대상(`src`·`api`·`server`·`scripts`)에서 뺐다.

## B. Postgres 포트

`lib/model.ts`의 `Database`는 `prepare(sql).bind(...).first/all/run` + `batch`뿐이라, 저장소를 바꾸는 일은
**파일 하나를 쓰는 일**이다. 도메인은 한 줄도 고치지 않았다.

- `server/pgPort.ts` — `?` → `$1…$n`(작은따옴표 안은 건드리지 않는다), `run()`은 `rowCount`, `batch`는 한 연결에서
  트랜잭션(하나라도 실패하면 전부 되돌린다 — "일정이 겹치면 낙찰 전체 취소"가 여기에 기댄다).
- `scripts/pg-schema.mjs` → `db/marketplace.pg.sql` — SQLite 마이그레이션을 Postgres 스키마로 변환한다.
  표 30개·외래키 29개·트리거 17개. 손으로 옮기면 한 컬럼이 조용히 빠져도 모르므로 변환을 코드로 두었다.

### 방언 차이를 어디서 흡수했나

| 차이 | 어디서 | 어떻게 |
|---|---|---|
| 자리표시자 `?` / `$n` | 포트 | 문자열 리터럴을 건너뛰며 변환 |
| `instr(a,b)` (SQLite 전용) | 스키마 | 같은 이름의 SQL 함수를 만들어 앱 SQL을 그대로 둔다 |
| 예약어 `end` (calendar_events) | 앱 SQL | `"end"` — 두 방언 모두 큰따옴표를 식별자로 읽는다 |
| `INSERT OR IGNORE` | 앱 SQL | `ON CONFLICT DO NOTHING` (SQLite 3.24+·Postgres 공통) |
| 외래키 선언 순서 | 스키마 | 표를 모두 만든 뒤 `ALTER TABLE`로 건다(Postgres는 앞선 참조를 거부한다) |
| `RAISE(ABORT,'X')` 트리거 | 스키마 | plpgsql 함수 + 트리거(`RAISE EXCEPTION 'X'`) |
| 낙관적 잠금 가드 | 앱 SQL | `abs(-9223372036854775808)`은 Postgres가 **파싱 단계에서** 거부하고, 상수식이라 계획 단계에서 접혀 안 타는 가지도 평가된다. 부분질의를 끼워 상수가 아니게 만들어 두 방언 모두 해당 가지를 탈 때만 넘치게 했다 |

## C. 검증 경로

- `tests/*.integration.test.ts` + `lib/marketplace/*.test.ts` → **Node 내장 SQLite**(v17 원본 방식). 도메인 규칙의 증거.
- `tests/pg.port.test.ts` → **진짜 Postgres**. 스키마 변환·자리표시자·batch·트리거가 실제로 같은지 본다.
  `DATABASE_URL`이 없으면 건너뛴다(로컬 게이트는 그대로 돈다). CI `server` job이 `npm run test:pg`로 돌린다.

## D. 하지 않은 것

- 화면·배포 경로는 그대로다. Next.js 앱 셸과 v17 화면은 29-2, 스냅샷·보관함 삭제는 29-3.
- v17의 ChatGPT 헤더 인증(`app/chatgpt-auth.ts`)은 **가져오지 않았다**. 로그인과 검증 체계는 우리 것을 쓴다는 결정이라
  (`../../참고_v17_대조.md` §3), 29-2에서 우리 세션(`server/session.ts`) → v17 `User` 어댑터 한 곳만 만들어 물린다.
  그 헤더 방식은 호스트가 넣어 주지 않는 곳에서는 누구나 남의 신원을 주장할 수 있어 우리 배포에 그대로 쓸 수 없다.
- 사진 저장소(R2 자리)는 아직 없다 — 29-4.
