## 상 (High)

### 28-25-01 · 가격 패키지 도메인 부재 (시안 3 "가격 패키지")
→ 요구: `ServicePackage { id, name, category, price, description, active }` (price는 정수 KRW).
- `addPackage()`: 이름 공백 불가, 가격은 양의 정수(0·음수·소수 거부), 카테고리는 ALL_CATEGORIES 내만.
- `updatePackage(id, patch)` / `togglePackage(id)` / `removePackage(id)` — 없는 id 거부.
- `listPackages()`(관리자용 전체) / `activePackages()`(고객용 — active **그리고** 비활성 카테고리 제외).
- 기본 패키지 시드(카테고리별 3~4개, 홈페이지가 비어 보이지 않게). 스냅샷 `packages?`+`packageSeq?` 하위 호환 + 요소 검증 + **도메인 테스트 필수**.

### 28-25-02 · 관리자 패키지 관리 UI 부재 (시안 3)
→ 요구: 관리자 설정 탭에 "가격·패키지" 카드 — 목록(카테고리 필·가격·노출 상태), 추가 폼(이름/카테고리/가격/설명), 노출/숨김 토글, 삭제, 입력 오류는 도메인 메시지 그대로 표시.

### 28-25-03 · 고객 웹에 가격 신호 부재
→ 요구: 랜딩에 "표준 가격" 섹션 — `activePackages()`를 카테고리 텍스트 필 + 정찰 가격으로 노출(28-19 플랫 문법: 리스트 행, 장식 금지), "정확한 금액은 견적에서 확정됩니다" 고지. 관리자 카테고리 토글과 연동(비활성 카테고리 패키지는 자동 숨김).
