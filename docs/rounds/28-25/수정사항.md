# 28-25 수정사항 (Claude) — 파트너 실적·캘린더 라운드

기반: `28-24` 복사본(스크래치 wf28-25)에서 작업. 28-24 감사 4건 전부 반영.
시안 2("사업자 파트너 UI")의 파트너 센터 격차 2종을 닫는다: **이번 달 실적 요약** + **일정 월 캘린더**, 그리고 일감 정렬.

## 28-24-01 · 이번 달 실적 요약 [반영]

- 도메인 `platform.ts`에 `monthSummary(month)` 추가 — `monthlyReport()`에서 해당 월(YYYY-MM) 행을 찾아 반환, 없으면 **0 행**(jobCount/총액/수수료/지급액 모두 0) 반환. 도메인 테스트 2건 추가(있는 달 = monthlyReport 행과 동일, 없는 달 = 0 행) → vitest 151→**152**.
- `Dashboard.tsx`에 "이번 달 실적 요약 (YYYY-MM)" 카드 — 정산 예정액(대형 숫자), 완료 N건·확정 지급액, 낙찰률·평균 평점. 기존 `.bidstats` 숫자-우선 문법 재사용(새 장식 없음, 28-19 문법 유지).

## 28-24-02 · 일정 월 캘린더 [반영]

- `Schedule.tsx` 상단에 월 캘린더 카드:
  - `‹`/`›` 월 이동(`cal-nav`), `YYYY년 M월` 헤더, 요일 헤더(일~토).
  - 날짜 계산은 **UTC 규약 유지**: `Date.UTC(cy, cm-1, 1).getUTCDay()`(시작 요일) + `Date.UTC(cy, cm, 0).getUTCDate()`(말일).
  - 날짜 칸에 해당일 방문 슬롯의 **카테고리 미니 라벨**(최대 2개 + `+N`), 오늘은 날짜 숫자에 브랜드 원형 강조.
  - **날짜 칸 클릭 = 기존 날짜 필터 연동**: `setDate(iso)` + `setFilterByDate(true)` → 아래 리스트가 즉시 그 날짜로 필터되고, 칸에 `selected`(브랜드 보더+소프트 배경) 표시.
- CSS `components.css`: `.cal-grid`(7열 grid), `button.cal-cell`(전역 버튼 스타일을 카드형 플랫 셀로 오버라이드 — 배경 `--card`, 보더 `--line`, 그림자·변형 없음), 모바일 ≤560px에서는 라벨 대신 **점(`.cal-dot`)** 표기 + 셀 높이 축소 → 가로 스크롤 없음.

## 28-24-03 · 일감 정렬 [반영]

- `Jobs.tsx` 툴바에 정렬 셀렉트(`aria-label="정렬"`): **최신순(기본)** / **희망일 임박순**(desiredDate 오름차순) / **예산 높은순**(숫자 예산 내림차순, **예산 없는 건 뒤로**). 동률은 ID 최신순. 필터(키워드·카테고리)와 조합 동작.

## 28-24-04 · 실측 검증 [반영]

- 캘린더 실측: 오늘 강조 true / 슬롯 라벨 true / 날짜 클릭 → selected 표시 true + 날짜 필터 체크 true + 리스트 1행 / `›` 이동 시 헤더 "2026년 10월". 스크린샷 `28-25-calendar.png`, 모바일 390px `28-25-calendar-mobile.png`(가로 스크롤 false).
