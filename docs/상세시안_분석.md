# 상세 시안 분석 (2026-09-01, 사용자 제공 5장 — "상세야")

전체 시스템 맵 1장 + 리뉴얼 상세 4장(파트너 UI / 관리자 CMS·운영 설정 / 관리자 거래 관제 / 고객 거래 상세). 28-15에 개통한 3역할 구조의 **기준 시안**으로 삼는다. 여기 기록한 매핑·로드맵이 이후 라운드 감사의 근거다.

## 1. 전체 시스템 맵 (PC·Mobile 통합)

| 역할 | 시안 화면 | 현재(28-15) 대응 | 상태 |
|---|---|---|---|
| 고객 | 서비스 소개 | 없음 (로그인 전 랜딩 개념) | 로드맵 후순위 — 인증 없음 스코프 |
| 고객 | 작업 요청 | 수리 요청 탭 | ✅ 있음 |
| 고객 | 입찰 비교 | 견적함 (단일 파트너라 비교 아님) | 부분 — 다중 파트너는 범위 밖 |
| 고객 | 업체 상세 | 없음 | 로드맵 (파트너 프로필 노출) |
| 고객 | 결제/예약·영수증 | 없음 (결제는 시뮬레이션 범위) | 로드맵 — 결제 내역 표시로 대체 |
| 고객 | 거래 상세(진행/채팅/추가 작업/리뷰·A/S) | 없음 | **28-16 착수 (핵심)** |

| 관리자 | 대시보드·거래 리스트·거래 상세·정산 | 현황·요청 관리·정산 감독 | 거래 상세 **28-16 착수** |

## 2. 파트너 UI 상세 (시안 2) — 격차

- 인증 현황(사업자 등록·승인 진행률): 프로필 확장 개념 — 로드맵.
- 이번 달 실적 요약(정산 예정액·완료 건수·낙찰률): 정산 예정액·낙찰률은 있음. 월 단위 요약 카드 — 로드맵(소).
- 일감 찾기 필터(지역/종류/예산/일정): 키워드·카테고리 있음. 예산·일정 필터 — 로드맵(소).
- **작업 현황 칩 필터(입찰 중/낙찰/작업 예정/진행 중/완료)**: 내 작업 탭에 없음 → **28-16 착수**.
- 입찰 제출 폼(포함/제외 항목, 고객 메시지): 금액 구성+메모 있음 — 부분 대응.
- 일정 캘린더 월 뷰: 리스트만 있음 — 로드맵.

## 3. 관리자 CMS·운영 설정 (시안 3) — 격차

카테고리 토글·질문 빌더·가격 패키지·홈페이지 콘텐츠 발행: 전부 신규 도메인(플랫폼 설정 저장) 필요. **로드맵 1묶음(CMS 라운드)** — 착수 순서는 거래 관제보다 뒤(거래 흐름이 먼저 완결되어야 함).

## 4. 관리자 거래 관제 (시안 4) — 격차

- 관제 지표(신규/진행/결제 보류/분쟁): 현황 탭이 부분 대응(분쟁 개념 없음).
- **거래 상세 + 진행 타임라인**(등록→입찰→선택→결제→방문→시작→추가 승인→완료→리뷰→A/S): 없음 → **28-16 착수** (현 도메인으로 파생 가능한 단계까지: 등록→견적→낙찰→방문 예약→시공→추가 작업→완료→정산).
- 분쟁/클레임(유형·심각도·증빙·처리 상태): 신규 도메인 — 로드맵.
- 정산 대기 목록·결제 확인/정산 보류 액션: 정산 감독이 부분 대응. 관리자 정산 확정 액션 — 로드맵(소).

## 5. 고객 거래 상세 (시안 5) — 격차 (**이번 라운드 핵심**)

- 거래 상세(서비스/주소/예약 일시/업체/결제 예정 금액): → **28-16**: 고객 홈 카드 → 상세 화면(견적 분해·방문 일정·최종 금액).
- 진행 단계 타임라인: → **28-16** 도메인 `requestTimeline()` 파생.
- **추가 작업 승인 요청(내용/사유/추가 비용 → 고객 승인/거절)**: 현재는 파트너가 즉시 확정 — 시안의 핵심 흐름 위반. → **28-16**: 도메인에 승인 흐름(파트너 요청 pending → 고객 승인/거절) 도입.
- 업체와 채팅: 신규 도메인(메시지) — 로드맵.
- 리뷰 작성·A/S 요청: 신규 도메인 — 로드맵.
- 방문 전 안내·정책 안내: 정적 콘텐츠 — 상세 화면에 포함(소).

## 라운드 로드맵 (감사 우선순위 제안)

1. **28-16 (이번)**: 고객 거래 상세 + 진행 타임라인 + 추가 작업 승인 흐름 + 파트너 작업 칩 필터 + 관리자 거래 상세.
2. 28-17 후보: 리뷰·평점(고객 작성 → 파트너 후기 표시 → 관리자 리뷰 관리) — 시안 2·5 공통.
3. 28-18 후보: 분쟁/클레임 + A/S 접수(고객 요청 → 관리자 처리 상태) — 시안 4·5.
4. 28-19 후보: 파트너 월 실적 요약 + 일감 필터 확장 + 일정 캘린더 월 뷰 — 시안 2.
5. 28-20 후보: CMS 라운드(카테고리 관리·안내 문구·FAQ) — 시안 3.
6. 이후: 결제 표시 계층(예약금·결제 내역·영수증 뷰), 업체 상세 노출 — 시안 1·5.

**범위 밖 유지**: 실결제·인증(로그인/회원가입)·다중 계정·실시간 채팅 인프라. 모두 단일 시연 계정 + 로컬 도메인 시뮬레이션 원칙(README) 안에서 UI·도메인 흐름만 구현한다.
