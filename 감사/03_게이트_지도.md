## 3. 구조적으로 안 보이는 것 세 가지 (감사 포인트)

### 3-1. 컴포넌트 `.tsx` 테스트는 **수집되지 않습니다**

`vitest.config.ts` 의 `include` 가 이렇습니다:

```
src/**/*.test.{ts,tsx}   server/**/*.test.ts   lib/**/*.test.ts
tests/**/*.test.ts       scripts/**/*.test.mjs
```

`components/**` 이 없습니다. 즉 **화면 컴포넌트의 단위 테스트는 존재해도 돌지 않습니다.**
화면 동작은 오직 브라우저 봇만이 지킵니다. 봇이 약하면 그 층에는 아무 그물이 없습니다.

### 3-2. `prettier` 가 보는 범위도 좁습니다

```
src/**   server/**/*.ts   scripts/**/*.mjs   *.{ts,json}
```

`components/` `lib/` `tests/` `app/` 은 **포맷 검사 대상이 아닙니다.**

### 3-3. 이미지가 실제로 내려왔는지 재는 자리는 저장소 전체에 **한 곳뿐**입니다

제가 센 실제 숫자입니다:

| 패턴 | 횟수 |
|---|---|
| `waitFor({ state: 'visible' })` | `e2e-roles` **14** · `e2e-trade` 1 · `e2e-signup` 1 = **16** |
| `naturalWidth` 를 실제로 재는 자리 | **1** (29-32 가 넣은 커버 확인 딱 하나) |

`visible` 은 **DOM 에 있고 박스 크기가 0 이 아니면** 통과합니다. CSS 가 크기를 주는 요소라면
그 안의 그림이 403 이어도 통과합니다. **나머지 15곳이 전부 같은 함정 위에 있는지, 아니면
이미지가 아니라 텍스트·버튼이라 무해한지 — 이것이 우선순위 1번 부탁입니다.**
